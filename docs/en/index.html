OmniDB Project

The lightweight, powerful, and open-source database management tool is back to empower modern development workflows.

Actively developed by the author of PgArachne and other tools — bridging robust database administration with modern, thin-client architectures.

Drag the handle — same workspace, light or dark.

Why OmniDB?

⚡

Rewritten for Speed

Python → Go. Queries execute and the UI responds without an interpreter in the way.

📦

Featherweight Binary

The old Electron/NW.js shell is gone. Wails now drives the app through the OS’s own native webview.

🖥️

Every Platform, One Release

macOS (Apple Silicon & Intel), Linux, and Windows build and ship from the same release.

🗄️

Seven Engines, One Workspace

PostgreSQL, MySQL, MariaDB, Oracle, MS SQL Server, Firebird and SQLite in one tabbed workspace.

🔒

Actively Hardened

Real fixes — SQL injection, XSS, IDOR — land continuously. See the changelog. On macOS the app runs in the App Sandbox.

📤

Export Anywhere

Straight to CSV, XLSX, TSV, Markdown, JSON, or XML — and a whole PostgreSQL schema to DBML.

📈

See What the Server Is Doing

A live monitoring dashboard, connected users with one-click termination, and a LISTEN/NOTIFY listener.

🛡️

Roles & Privileges at a Glance

Browse PostgreSQL roles, memberships and effective privileges — inherited ones included — and grant or revoke in place.

🌍

Speaks Your Language

English, Čeština, Deutsch, Español, Français, Italiano, Português, 日本語 and 한국어 — or just follow your system.

Install OmniDB

🍺

Homebrew macOS

Recommended for macOS — the cask auto-detects Apple Silicon or Intel.

brew install heptau/tap/omnidb
🪟

winget Windows

Recommended for Windows — installs and upgrades through the built-in Windows Package Manager.

winget install heptau.OmniDB
⬇️

GitHub Releases macOS · Linux · Windows

Download the self-contained archive for your platform — no installer, no separate runtime.
