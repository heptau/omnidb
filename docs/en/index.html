Why OmniDB?

⚡

Rewritten for Speed

Python → Go. Queries execute and the UI responds without an interpreter in the way.

📦

Featherweight Binary

The old Electron/NW.js shell is gone. Wails now drives the app through the OS's own native webview.

🖥️

Every Platform, One Release

macOS (Apple Silicon & Intel), Linux, and Windows build and ship from the same release.

🗄️

Five Engines, One Workspace

PostgreSQL, MySQL, MariaDB, Oracle and SQLite in one tabbed workspace.

🔒

Actively Hardened

Real fixes — SQL injection, XSS, IDOR — land continuously. See the changelog.

📤

Export Anywhere

Straight to CSV, XLSX, TSV, Markdown, JSON, or XML.
