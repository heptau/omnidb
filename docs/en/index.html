OmniDB Project Revival

The lightweight, powerful, and open-source database management tool is back to empower modern development workflows.

Project Status: We are active!

OmniDB is being actively revived by the creators of PgArachne. Our mission is to bridge the gap between robust database administration and modern, thin-client architectures.

Current Release: Optimized version for macOS (Apple Silicon and Intel) is now available. Support for Windows and Linux is in active development.

Why OmniDB?

Zero Installation

Experience a truly lightweight web-based interface. Manage your databases from any browser without bulky software packages.

Performance First

Optimized for modern hardware and seamlessly integrated with PgArachne's JSON-RPC gateway for near-instant query execution.

Real-time Collaboration

Built for teams. Share schemas, saved queries, and workspace configurations in a unified, collaborative environment.
