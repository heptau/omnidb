Datenbanken verwalten

Nachdem Sie eine Verbindung erstellt haben, können Sie sie auswählen, indem Sie in der Verbindungsübersicht auf die Aktion Select Connection (Verbindung auswählen) klicken. Sie werden sehen, dass die Verbindung durch eine Art äußeren Tab dargestellt wird, der Connection Tab (Verbindungs-Tab) genannt wird. Und dieser gesamte Bereich heißt Workspace Window (Arbeitsbereichsfenster).

Bereiche des Workspace-Fensters

Diese Oberfläche besteht aus mehreren Elementen:

  • 1) Connections (Verbindungen): Öffnet ein Popup mit der Connections-Übersicht
  • 2) Outer Tabs (Äußere Tabs): Mit OmniDB können Sie mehrere Datenbanken gleichzeitig bearbeiten. Jede Datenbank ist über einen äußeren Tab zugänglich. Äußere Tabs können auch verbindungsunabhängige Funktionen beherbergen, wie etwa die Funktion Snippets
  • 3) Options (Optionen): Zeigt den aktuell angemeldeten Benutzer an, und falls der Benutzer ein Superuser ist, auch einen Link zur Benutzerverwaltung. Zeigt außerdem Links zu Benutzereinstellungen, installierten Plugins, Abfrageverlauf, Informationen und Abmelden.

Äußerer Verbindungs-Tab

Der äußere Tab mit dem Namen PostgreSQL - testdb trägt diesen Namen wegen des Alias (PostgreSQL), das wir in der Verbindung zur Datenbank testdb angegeben haben. Dieser Tab ist ein Connection Outer Tab (äußerer Verbindungs-Tab). Beachten Sie den kleinen Tab mit einem Kreuz neben dem äußeren Tab PostgreSQL - testdb. Damit können Sie einen neuen äußeren Tab erstellen, der automatisch ein Connection Outer Tab ist. Der Snippet Outer Tab hingegen ist fest und steht immer an erster Stelle.

Ein neuer Connection Outer Tab zeigt automatisch immer auf die erste Verbindung in Ihrer Liste der Datenbankverbindungen. Oder, falls Sie auf die Aktion Select Connection geklickt haben, zeigt er auf die ausgewählte Verbindung. Betrachten Sie die Elemente innerhalb dieses Tabs:

  • 1) Connection Selector (Verbindungsauswahl): Zeigt alle Verbindungen an und lässt den Benutzer die aktuelle auswählen
  • 2) Tree of Structures (Strukturbaum): Zeigt einen hierarchischen Baum, in dem Sie durch die Datenbankelemente navigieren können
  • 3) Properties and DDL Panels (Eigenschaften- und DDL-Panels): Zeigen Eigenschaften und DDL zum aktuell ausgewählten Knoten in der Baumansicht an
  • 4) Inner Tabs (Innere Tabs): Ermöglichen dem Benutzer, Aktionen in der aktuellen Datenbank auszuführen. Es gibt mehrere Arten innerer Tabs für die aktuelle Datenbank. Durch Klicken auf den letzten kleinen Tab mit Kreuz können Sie einen neuen Tab hinzufügen. Ein neuer Tab kann ein Query Tab (Abfrage-Tab), Console Tab (Konsolen-Tab), Monitoring Dashboard (Überwachungs-Dashboard) oder Backends sein

  • 5) Inner Tab Content (Inhalt des inneren Tabs): Kann je nach Art des inneren Tabs variieren. Die Abbildung zeigt einen Query Tab, und in diesem Fall besteht der Inhalt aus einem SQL-Editor mit Syntaxhervorhebung, automatischer Vervollständigung sowie Suchen & Ersetzen
  • 6) Inner Tab Actions (Aktionen des inneren Tabs): Können je nach Art des inneren Tabs variieren. Für einen Query Tab sind dies Run (Ausführen), Indent SQL (SQL einrücken), Command History (Befehlsverlauf), Explain, Explain Analyze, Autocommit und Export Data (Daten exportieren)
  • 7) Inner Tab Results (Ergebnisse des inneren Tabs): Bei einem Query Tab wird nach Klick auf die Execute-Schaltfläche oder Drücken des Tastenkürzels zum Ausführen (Alt-Q) eine Ergebnistabelle mit den Abfrageergebnissen im Unter-Tab Data angezeigt. Ruft die Abfrage eine Funktion auf, die Meldungen ausgibt, werden diese im Unter-Tab Messages angezeigt. Haben Sie stattdessen auf Explain oder Explain Analyze geklickt, wird der Ausführungsplan der Abfrage im Unter-Tab Explain angezeigt.

Arbeiten mit Datenbanken

Werfen Sie einen Blick auf Ihre Verbindungsauswahl. OmniDB zeigt immer auf die erste verfügbare Verbindung, Sie können dies jedoch durch Klicken auf die Auswahl ändern.

Wählen Sie die Verbindung PostgreSQL aus. Gehen Sie nun zum Baum direkt unter der Auswahl und klicken Sie, um den Wurzelknoten PostgreSQL zu erweitern.

Bedenken Sie, dass nach 30 Minuten ohne Aktionen an der Datenbank ein Authentication-Popup (Authentifizierung) erscheint, was bedeutet, dass das Passwort, das OmniDB verschlüsselt im Arbeitsspeicher abgelegt hat, nun abgelaufen ist. Wie bereits erläutert, ist dies wichtig für die Sicherheit Ihrer Datenbank. Nachdem Sie das korrekte Passwort eingegeben haben, sehen Sie, dass der PostgreSQL-Knoten nun die PostgreSQL-Version anzeigt und außerdem erweitert wurde, wobei die aktuelle Datenbankverbindung sowie instanzweite Elemente angezeigt werden: Databases (Datenbanken), Tablespaces (Tablespaces), Roles (Rollen) und Replication Slots (Replikationsslots).

Sie können sich mit einer einzelnen PostgreSQL-Datenbank verbinden und über dieselbe Verbindung auch andere Datenbanken in derselben PostgreSQL-Instanz erreichen. Die aktuell aktive Datenbank wird unterhalb der Verbindungsauswahl angezeigt.

Um sich mit einer anderen Datenbank zu verbinden, erweitern Sie den entsprechenden Knoten dieser Datenbank. Es erscheint ein Popup mit der Frage, ob Sie die aktive Datenbank wirklich wechseln möchten.

Klicken Sie auf Yes (Ja), und OmniDB wechselt die aktive Datenbank zur ausgewählten Datenbank. Dies spiegelt sich in der Anzeige Active database (Aktive Datenbank) sowie im Namen des äußeren Tabs wider.

Erweitern Sie nun den Knoten Schemas (Schemata). Sie sehen alle Schemata in der aktuellen Datenbank (bei PostgreSQL werden TOAST- und temporäre Schemata nicht angezeigt).

Klicken Sie nun, um das Schema public zu erweitern. Sie sehen verschiedene Arten von Elementen, die in diesem Schema enthalten sind.

Klicken Sie nun, um den Knoten Tables (Tabellen) zu erweitern, und Sie sehen alle Tabellen im Schema public. Erweitern Sie eine beliebige Tabelle, und Sie sehen ihre Spalten, den Primärschlüssel, Fremdschlüssel, Constraints, Indizes, Regeln, Trigger und Partitionen.

Um Datensätze innerhalb einer Tabelle anzuzeigen, klicken Sie mit der rechten Maustaste darauf und wählen Sie *Data Actions

Query Data*.

Beachten Sie, dass OmniDB einen neuen SQL-Editor mit einer einfachen Abfrage zum Auflisten der Tabellendatensätze öffnet. Die Datensätze werden in einer Ergebnistabelle direkt unter dem Editor angezeigt. Diese Tabelle lässt sich per Tastatur bedienen, als würden Sie eine Tabellenkalkulation verwenden. Sie können auch Daten aus einzelnen Zellen oder Zellblöcken (die per Tastatur oder Maus ausgewählt werden können) kopieren und in eine beliebige Tabellenkalkulation einfügen.

Sie können die Abfrage im SQL-Editor bearbeiten und einfache oder komplexere Abfragen schreiben. Klicken Sie zum Ausführen auf die Aktionsschaltfläche, oder drücken Sie die Tastenkombination Alt-Q. Übersteigen die Ergebnisse 100 Datensätze, erscheinen die zusätzlichen Schaltflächen Fetch More (Weitere abrufen) und Fetch All (Alle abrufen). Weitere Details dazu in den nächsten Kapiteln.

Arbeiten mit mehreren Tabs innerhalb derselben Verbindung

Innerhalb einer einzelnen Verbindung können Sie mehrere innere Abfrage-Tabs erstellen, indem Sie auf den letzten kleinen Tab mit Kreuz klicken und dann Query Tab auswählen.

In OmniDB können Sie mehrere SQL-Anweisungen und Prozeduren parallel ausführen. Während der Ausführung wird im Tab ein Symbol angezeigt, das den aktuellen Status kennzeichnet. Ist ein Vorgang abgeschlossen und Sie befinden sich nicht im entsprechenden Tab, zeigt dieser Tab ein grünes Symbol, das anzeigt, dass die dort ausgeführte Routine nun abgeschlossen ist.

Durch Klicken auf die Cancel-Schaltfläche (Abbrechen) können Sie einen in der Datenbank laufenden Prozess abbrechen.

Sie können einen Tab auch per Drag & Drop verschieben, um seine Reihenfolge zu ändern. Dies funktioniert sowohl bei inneren als auch bei äußeren Tabs.

Zusätzlich können Sie Tastenkürzel zur Verwaltung innerer Tabs (SQL-Abfrage) verwenden. Dies sind die Standardkürzel unter Windows/Linux (macOS ersetzt Alt durch Strg); alle lassen sich im Tab „Tastenkürzel“ des Einstellungsdialogs neu belegen:

  • Alt-I: Fügt einen neuen inneren Tab ein
  • Alt-Umschalt-Q: Entfernt den aktuellen inneren Tab
  • Alt-O: Wechselt den Fokus zum inneren Tab links
  • Alt-P: Wechselt den Fokus zum inneren Tab rechts

Für äußere (Verbindungs-)Tabs gibt es derzeit keine Tastenkürzel — verwenden Sie hierfür das Verschieben per Drag & Drop oder die Maus.

Alle SQL-Abfrage-Tabs werden automatisch gespeichert, sobald Sie sie ausführen. Selbst wenn Sie das OmniDB-Fenster oder den Browser-Tab schließen, sind sie bereits in der OmniDB- Benutzerdatenbank gespeichert. Sie werden automatisch wiederhergestellt, wenn Sie OmniDB erneut öffnen (bei Verwendung der App), es in einem anderen Browserfenster öffnen (bei Verwendung des Servers), oder selbst wenn Sie auf das Connections-Fenster geklickt oder sich abgemeldet haben. Das Entfernen eines äußeren oder inneren Tabs über die Benutzeroberfläche löscht ihn dauerhaft, sodass er nicht wiederhergestellt wird.
