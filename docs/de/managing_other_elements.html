Weitere Elemente verwalten

Alle PostgreSQL-Strukturen lassen sich mithilfe von SQL-Vorlagen verwalten. Das gibt dem Benutzer mehr Kontrolle, als es die Verwendung grafischer Formulare zur Bearbeitung von Strukturen könnte.

Betrachten wir als Beispiel die Sequenzen innerhalb des Schemas public der Datenbank ds2. Um eine neue Sequenz zu erstellen, klicken Sie mit der rechten Maustaste auf den Knoten Sequences und wählen Sie Create Sequence.

Nachdem Sie den Namen der Sequenz geändert haben, können Sie weitere Befehlsoptionen einkommentieren und nach Ihren Bedürfnissen anpassen. Sobald der gesamte Befehl passt, führen Sie ihn einfach aus, und die neue Sequenz wird erstellt:

Mit einem Rechtsklick auf eine bestehende Sequenz können Sie diese ändern oder löschen. Das funktioniert genauso wie das Erstellen, über eine vom Benutzer anzupassende SQL-Vorlage.
