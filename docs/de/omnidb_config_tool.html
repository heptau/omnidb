OmniDB-Konfigurationstool

Hinweis: Das eigenständige CLI-Dienstprogramm omnidb-config/omnidb-config-app/omnidb-config-server, das auf dieser Seite beschrieben wird, gehörte zum vorherigen Python/Django-basierten Build und ist nicht Teil der aktuellen Veröffentlichung. Die einzelne omnidb-server-Binärdatei akzeptiert nur -A/--app (Desktop-App-Modus) und -d/--homedir (Home-Verzeichnis wählen), dokumentiert im Kapitel Installation. Die Wartungsaufgaben, die das alte Tool bot, können weiterhin manuell erledigt werden, wie unten beschrieben.

Home-Verzeichnis

OmniDB speichert alles — die omnidb.db-Datenbank (Benutzer, Verbindungen und andere App-Daten) und einen temp-Ordner für exportierte Dateien — in einem einzigen Home-Verzeichnis. Standardmäßig ist dies ~/.omnidb/omnidb-app (Desktop-Modus) oder ~/.omnidb/omnidb-server (Server-Modus); verwenden Sie -d /irgendein/pfad, um ein anderes zu wählen.

Benutzer erstellen

Derzeit gibt es keine CLI-Option, um einen Benutzer ohne Öffnen von OmniDB zu erstellen. Beim ersten Start mit einem leeren Home-Verzeichnis erstellt OmniDB automatisch einen Standard-Superuser admin/admin — melden Sie sich damit an und erstellen Sie weitere Benutzer über den Bildschirm Users (Benutzer) oder ändern Sie das Standard-Passwort.

Vakuumieren

OmniDB hat eine einzige SQLite-Datenbank, omnidb.db, die alle Benutzer, Verbindungen und andere OmniDB-bezogene Daten speichert. Da es sich um eine einfache SQLite-Datei handelt, können Sie sie mit jedem SQLite-Client vakuumieren, während OmniDB nicht läuft, z. B.:

user@machine:~$ sqlite3 ~/.omnidb/omnidb-app/omnidb.db 'VACUUM;'

Datenbank zurücksetzen

Wenn Sie alle OmniDB-Informationen löschen und eine saubere Datenbank wie bei der Neuinstallation erhalten möchten, beenden Sie OmniDB und löschen Sie die Datei omnidb.db im Home-Verzeichnis (oder verschieben Sie sie zur Seite). Eine neue, leere Datenbank — mit einem frischen Standard-Benutzer admin/admin — wird automatisch beim nächsten Start von OmniDB erstellt. Gehen Sie dabei vorsichtig vor: Dieser Vorgang kann nicht rückgängig gemacht werden.

Temporäre Dateien löschen

Exportierte Abfrageergebnisse (CSV/XLSX/usw.) werden in den temp-Ordner innerhalb des Home-Verzeichnisses geschrieben. Es ist sicher, dessen Inhalt jederzeit manuell zu löschen, während OmniDB nicht läuft; OmniDB erstellt ihn bei Bedarf neu.
