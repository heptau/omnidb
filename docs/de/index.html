Wiederbelebung des OmniDB-Projekts

Das leichtgewichtige, leistungsstarke und quelloffene Datenbank-Management-Tool ist zurück, um moderne Entwicklungs-Workflows zu unterstützen.

Aktiv wiederbelebt vom Autor von PgArachne — eine Brücke zwischen robuster Datenbankadministration und moderner Thin-Client-Architektur.

Ziehen Sie den Griff — derselbe Arbeitsbereich, hell oder dunkel.

⇔
Dunkel Hell

OmniDB installieren

🍺

Homebrew macOS

Empfohlen für macOS — das Cask erkennt Apple Silicon oder Intel automatisch.

brew install --cask heptau/tap/omnidb
⬇️

GitHub Releases macOS · Linux · Windows

Laden Sie das eigenständige Archiv für Ihre Plattform herunter — kein Installer, keine separate Laufzeitumgebung.

  • macOS (Apple Silicon)
  • macOS (Intel)
  • Linux (x64)
  • Windows (x64)

Vollständige Installationsanleitung: → Ausführlicher Installationsleitfaden

macOS ist vollständig verifiziert; Linux- und Windows-Builds durchlaufen dieselbe CI-Pipeline, wurden aber noch nicht auf echter Hardware getestet. Ältere Versionen (bis ca. 2020) aus dem ursprünglichen Repository werden nicht mehr gepflegt.

Warum OmniDB?

⚡

Neu geschrieben für mehr Geschwindigkeit

Python → Go. Abfragen werden ausgeführt und die Oberfläche reagiert, ohne dass ein Interpreter im Weg steht.

📦

Federleichte Binärdatei

Die alte Electron/NW.js-Hülle ist verschwunden. Wails steuert die App nun über die native Webview des Betriebssystems.

🖥️

Jede Plattform, ein Release

macOS (Apple Silicon & Intel), Linux und Windows werden aus demselben Release gebaut und ausgeliefert.

🗄️

Fünf Engines, ein Arbeitsbereich

PostgreSQL, MySQL, MariaDB, Oracle und SQLite in einem einzigen Arbeitsbereich mit Tabs.

🔒

Aktiv gehärtet

Echte Fixes — SQL-Injection, XSS, IDOR — kommen laufend hinzu. Siehe das Changelog.

📤

Export überallhin

Direkt nach CSV, XLSX, TSV, Markdown, JSON oder XML.
