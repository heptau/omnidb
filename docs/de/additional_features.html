Zusätzliche Funktionen

Benutzereinstellungen

Ebenfalls in der oberen rechten Ecke öffnet ein Klick auf das zahnradartige Symbol das Popup User Settings (Benutzereinstellungen). Es besteht aus vier Tabs:

  • Shortcuts (Tastenkürzel): Ermöglicht dem Benutzer, seine Tastenkürzel in OmniDB zu ändern.
  • Options (Optionen): Ermöglicht dem Benutzer, die Schriftgröße der Oberfläche zu ändern und CSV-bezogene Optionen zu konfigurieren (Zeichenkodierung, Trennzeichen). Das OmniDB-Design kann auf Automatisch (folgt der Farbschema-Einstellung Ihres Betriebssystems), Hell oder Dunkel gesetzt werden.
  • Formatting (Formatierung): Legt fest, wie der SQL-Formatierer (die Aktion Indent SQL, SQL einrücken) Ihre Abfrage umschreibt — Einrückungszeichen (Leerzeichen oder Tab), Einrückungsgröße (2/3/4), Kommastil (führend/nachgestellt) und Groß-/Kleinschreibung der Schlüsselwörter (beibehalten/GROSSSCHREIBUNG/Kleinschreibung). Legt außerdem die Ruler Column (Lineal-Spalte) fest — die vertikale Führungslinie, die der SQL-Editor zeichnet (24-999, Standardwert 128) — die live auf jeden geöffneten Editor angewendet wird.
  • Password (Passwort): Ermöglicht dem Benutzer, sein Passwort zu ändern.

Kontexthilfe

Die meisten Baumknoten (in der Regel gruppierende Knoten wie Schemas oder Tables) bieten Kontexthilfe an. Diese Funktion erreichen Sie per Rechtsklick auf den Baumknoten. Wenn Sie die Option Doc: … anklicken, öffnet OmniDB die entsprechende Seite der Online-PostgreSQL-Dokumentation in Ihrem Webbrowser (dem Standardbrowser des Systems in der Desktop-App, oder einem neuen Tab beim Betrieb als browserbasierter OmniDB Server). Dabei wird auch automatisch die passende Dokumentationsversion für den PostgreSQL-Server ausgewählt, mit dem Sie verbunden sind.

Snippets

Das Workspace Window (Arbeitsbereichsfenster) besitzt einen festen äußeren Tab mit einer nützlichen Funktion namens Snippets. Mit dieser Funktion können Sie Abfragen, Befehlsanweisungen und beliebige andere Arten von Text speichern. Sie können die Snippets auch in einer Verzeichnisstruktur nach Belieben organisieren. Alle von Ihnen erstellten Verzeichnisse und Snippets werden in der Benutzerdatenbank omnidb.db gespeichert und bleiben auch bei einem Upgrade von OmniDB erhalten.

Eine "+"/"-"-Fußleiste unterhalb des Snippet-Baums fügt ein Snippet unterhalb des gerade ausgewählten Ordners (oder der Baumwurzel) hinzu und löscht das jeweils ausgewählte Element; "-" bleibt deaktiviert, bis etwas Löschbares ausgewählt ist. Ein geöffneter Snippet-Tab zeigt einen kleinen Punkt neben seinem Titel, sobald der Editor vom gespeicherten Stand abweicht; dieser wird beim Speichern wieder entfernt. Beim Schließen eines Tabs wird nur dann eine Bestätigung abgefragt, wenn tatsächlich ungespeicherte Änderungen vorliegen.

Notify

Das Notify-Panel befindet sich in der Seitenleiste zwischen Database und Snippets und zeigt fortlaufend PostgreSQL-LISTEN/NOTIFY-, Oracle-DBMS_ALERT- und Firebird-POST_EVENT-Meldungen an. Kanäle werden pro Verbindung hinzugefügt, entfernt, pausiert und fortgesetzt und bleiben auch über einen Neustart der App hinweg erhalten; empfangene Nachrichten sind dagegen flüchtig — sie werden nur im Browser-Tab vorgehalten und beim Neuladen gelöscht. Nachrichten können kanalübergreifend oder gefiltert auf eine Auswahl angezeigt und pro Kanal oder insgesamt geleert werden. MySQL/MariaDB/MS SQL Server/SQLite zeigen anstelle des Features eine Meldung "nicht unterstützt" an. Die Notify-Sitzung einer Verbindung startet und stoppt zusammen mit ihrem Database-Tab, und das Panel teilt sich denselben horizontalen Streifen offener Verbindungen mit dem Database-Panel, sodass die Auswahl einer Verbindung in einem der beiden Panels das andere synchron hält.

Backend-Verwaltung

Durch Rechtsklick auf den Wurzelknoten des Baums, anschließendes Bewegen des Mauszeigers auf Monitoring (Überwachung) und Klicken auf Backends kann der Benutzer alle derzeit in der Datenbank ablaufenden Aktivitäten einsehen. Einige Informationen sind für normale Benutzer ausgeblendet und nur für Datenbank-Superuser sichtbar.

Durch Klicken auf das X in der Spalte Actions (Aktionen) können Sie das Backend beenden. Es erscheint ein Bestätigungs-Popup.

Eigenschaften und DDL

Durch Klicken auf die meisten Objekte in der Baumansicht (Tabellen, Sequenzen, Views, Rollen, Datenbanken usw.) kann der Benutzer eine sehr umfassende Liste der Eigenschaften des Objekts einsehen.

Im anderen Panel namens DDL kann der Benutzer den SQL-DDL-Quellcode einsehen, mit dem das Objekt neu erstellt werden kann. Der Benutzer kann diesen Text kopieren und einfügen, wo immer er möchte.

Daten exportieren

Der Query Tab (Abfrage-Tab) bietet die Möglichkeit, Daten aus Abfrageergebnissen als CSV, TSV, XLSX, Markdown, JSON oder XML zu speichern. Sobald Sie auf die Schaltfläche Export Data (Daten exportieren) klicken, startet ein abbrechbarer Hintergrundprozess, der die Daten in die Datei schreibt. Ist er abgeschlossen, stellt OmniDB einen Link namens Save (Speichern) bereit, über den der Benutzer die Datei herunterladen kann. Die CSV/TSV-Zeichenkodierung (Settings > Options) verwendet standardmäßig UTF-8 mit einem BOM, und ihre Codec-Liste ist in übersichtliche Kategorien gruppiert.

Alle Dateien werden in einem temporären Ordner innerhalb des OmniDB-Ordners gespeichert. OmniDB bereinigt diesen Ordner regelmäßig und behält dabei nur Dateien, die jünger als 24 Stunden sind.

Abfrageverlauf

Über den Query Tab können Sie auf die Schaltfläche Command History (Befehlsverlauf) klicken, um einen vollständigen, durchsuch- und durchblätterbaren Abfrageverlauf anzuzeigen.

SSH-Konsole

OmniDB bietet außerdem eine vollwertige SSH-Konsole.
