Rinascita del progetto OmniDB

Lo strumento di gestione database leggero, potente e open source è tornato per potenziare i moderni flussi di lavoro di sviluppo.

Rinato attivamente grazie all'autore di PgArachne — un ponte tra una solida amministrazione dei database e le moderne architetture thin-client.

Trascina la maniglia — stesso spazio di lavoro, chiaro o scuro.

Installa OmniDB

🍺

Homebrew macOS

Consigliato per macOS — il cask rileva automaticamente Apple Silicon o Intel.

brew install --cask heptau/tap/omnidb

Perché OmniDB?

⚡

Riscritto per la velocità

Python → Go. Le query vengono eseguite e l’interfaccia risponde senza un interprete di mezzo.

📦

Binario superleggero

Il vecchio shell Electron/NW.js è sparito. Ora Wails guida l’app tramite la webview nativa del sistema operativo.

🖥️

Ogni piattaforma, un’unica release

macOS (Apple Silicon e Intel), Linux e Windows vengono compilati e distribuiti dalla stessa release.

🗄️

Cinque motori, un unico spazio di lavoro

PostgreSQL, MySQL, MariaDB, Oracle e SQLite in un unico spazio di lavoro a schede.

🔒

Sicurezza rinforzata attivamente

Correzioni reali — SQL injection, XSS, IDOR — arrivano di continuo. Consulta il changelog.

📤

Esporta ovunque

Direttamente in CSV, XLSX, TSV, Markdown, JSON o XML.
