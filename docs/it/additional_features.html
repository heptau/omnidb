Funzionalità aggiuntive

Impostazioni utente

Sempre nell’angolo in alto a destra, cliccando sull’icona a forma di ingranaggio, OmniDB aprirà il popup Impostazioni utente. È composto da quattro schede:

  • Scorciatoie: Permette all’utente di modificare le proprie scorciatoie in OmniDB.
  • Opzioni: Permette all’utente di modificare la dimensione del carattere dell’interfaccia e configurare le opzioni relative al CSV (codifica, delimitatore). Il tema di OmniDB (Chiaro/Scuro) viene determinato automaticamente in base alla preferenza dello schema di colori del sistema operativo.
  • Formattazione: Configura il modo in cui il formattatore SQL (l’azione Indent SQL) riscrive la query — carattere di indentazione (spazi o tab), dimensione dell’indentazione (2/3/4), stile delle virgole (iniziale/finale), e maiuscole/minuscole delle parole chiave (mantieni/MAIUSCOLO/minuscolo).
  • Password: Permette all’utente di cambiare la propria password.

Guida contestuale

La maggior parte dei nodi dell’albero (generalmente quelli di raggruppamento come Schemas o Tables) offre una guida contestuale. Questa funzionalità è accessibile facendo clic con il tasto destro sul nodo dell’albero. Quando si fa clic sull’opzione Doc: …, OmniDB apre la pagina specifica della documentazione online di PostgreSQL nel browser web (il browser predefinito del sistema nell’app desktop, oppure una nuova scheda quando si esegue come OmniDB Server basato su browser). Sceglie inoltre la versione di documentazione corretta per il server PostgreSQL a cui si è connessi.

Snippet

La finestra di lavoro dispone di una scheda esterna fissa con una funzionalità utile chiamata Snippet. Con questa funzionalità è possibile memorizzare query, istruzioni da riga di comando e qualsiasi altro tipo di testo desiderato. È inoltre possibile organizzare gli snippet in una struttura ad albero di directory a proprio piacimento. Tutte le directory e gli snippet creati vengono memorizzati all’interno del database utente omnidb.db e persistono quando si aggiorna OmniDB.

Gestione dei backend

Facendo clic con il tasto destro sul nodo radice dell’albero, spostando poi il puntatore del mouse su Monitoring e infine facendo clic su Backends, l’utente può vedere tutte le attività in corso nel database. Alcune informazioni sono nascoste agli utenti normali; solo i superuser del database possono visualizzarle.

Facendo clic sulla X nella colonna Actions, è possibile terminare il backend. Apparirà un popup di conferma.

Proprietà e DDL

Facendo clic sulla maggior parte degli oggetti nella vista ad albero (tabelle, sequenze, viste, ruoli, database, ecc.), l’utente potrà visualizzare un elenco molto completo delle proprietà dell’oggetto.

Nell’altro pannello, chiamato DDL, l’utente potrà visualizzare il codice sorgente SQL DDL che può essere usato per ricreare l’oggetto. L’utente può copiare questo testo e incollarlo dove desidera.

Esportazione dati

La Query Tab offre un modo per salvare i dati dei risultati di una query in un file CSV o XLSX. Dopo aver cliccato sul pulsante Export Data, si avvia un processo in background annullabile che salva i dati nel file. Una volta completato, OmniDB fornisce un link chiamato Save, in modo che l’utente possa scaricare il file.

Tutti i file vengono memorizzati in una cartella temporanea all’interno della cartella di OmniDB. OmniDB pulisce regolarmente questa cartella, mantenendo solo i file più recenti di 24 ore.

Cronologia delle query

Dalla Query Tab è possibile fare clic sul pulsante Command History per visualizzare una scheda query completa, sfogliabile e ricercabile.

Console SSH

OmniDB offre anche una console SSH completa di tutte le funzionalità.
