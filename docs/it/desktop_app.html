App desktop

L’app desktop (OmniDB.app su macOS, OmniDB/OmniDB.exe su Linux e Windows) è una piccola finestra nativa attorno alla stessa interfaccia di OmniDB che la versione server offre ai browser. Avvia in background una propria copia privata di omnidb-server, in ascolto solo sulla macchina locale, e accede automaticamente come utente predefinito admin — non c’è alcuna pagina di accesso, nessuna icona Account e nulla da configurare. Vedi Installazione per sapere come ottenerla.

Dove si trovano i dati

Le connessioni salvate, gli snippet, le impostazioni, la cronologia delle query e così via sono conservati in ~/.omnidb/omnidb-app/ (il database utente omnidb.db, più una cartella temp per le esportazioni e la posizione salvata della finestra). Per mantenere un insieme di dati separato — ad esempio uno usa e getta per i test — avvia l’app con una directory home diversa:

open -a OmniDB --args -d /path/to/other/dir    # macOS
./OmniDB -d /path/to/other/dir                  # Linux
OmniDB.exe -d C:\path\to\other\dir              # Windows

La directory deve già esistere; una directory nuova e vuota viene preparata automaticamente al primo utilizzo. Le password salvate sono cifrate con una chiave conservata nell’archivio dei segreti del sistema operativo — vedi Sicurezza e server multiutente.

La barra dei menu

  • OmniDB: Informazioni su OmniDB, Preferenze… (Cmd/Ctrl-,), Importa dati dall'installazione precedente… (solo nella build sandbox per macOS, vedi sotto) ed Esci da OmniDB (Cmd/Ctrl-Q).
  • Edit e Window: i menu standard del sistema operativo (annulla/taglia/copia/incolla, riduci a icona, zoom, schermo intero, …).
  • Vista: passa a una sezione della barra laterale sinistra — Benvenuto (Cmd/Ctrl-Shift-W), Connessioni (Cmd/Ctrl-Shift-C), Database (Cmd/Ctrl-Shift-D), Notifiche (Cmd/Ctrl-Shift-N), Utenti connessi (Cmd/Ctrl-Shift-U), Snippet (Cmd/Ctrl-Shift-S) — più Attiva/disattiva albero del database (Cmd/Ctrl-B) e Attiva/disattiva pannello proprietà/DDL (Cmd/Ctrl-Shift-B).
  • Aiuto: Per iniziare (il tutorial interattivo), Scorciatoie da tastiera (apre le Impostazioni sulla categoria Scorciatoie), Visita omnidb.net e Repository GitHub.

I menu OmniDB, Vista e Aiuto vengono mostrati nella lingua scelta in Impostazioni > Aspetto > Lingua e cambiano non appena la modifichi; prima che la prima pagina sia caricata seguono la lingua del sistema operativo. I menu standard Edit e Window restano in inglese. Il titolo della finestra mostra la sezione in cui ti trovi (ad esempio OmniDB - Snippet).

Dimensione e posizione della finestra

Al primissimo avvio la finestra si apre ingrandita. In seguito si riapre con la dimensione, la posizione e lo stato ingrandito/ripristinato che aveva l’ultima volta che l’hai chiusa.

Link e file

I link a pagine esterne (le voci Doc: … dell’albero del database, i link della pagina di benvenuto, il menu Aiuto) si aprono nel browser web predefinito. Le esportazioni ed Esporta come DBML aprono la finestra nativa Salva con nome, così scegli direttamente dove salvare il file — vedi Scrittura di query SQL.

macOS: sandbox, dati precedenti e .pgpass

L’app per macOS gira nella App Sandbox, che le assegna una propria cartella home privata. Due conseguenze:

  • I dati di una precedente installazione non sandbox in ~/.omnidb non sono visibili automaticamente. Al primo avvio senza dati, OmniDB propone di importarli — scegli Import… e seleziona la cartella .omnidb precedente, oppure Not Now. Puoi fare lo stesso in seguito con OmniDB > Importa dati dall'installazione precedente….
  • ~/.pgpass non è leggibile finché non lo consenti. Quando una connessione PostgreSQL non ha una password memorizzata, la richiesta della password offre Concedi accesso a .pgpass…: seleziona una volta il tuo file .pgpass (in quella finestra i file nascosti sono visibili) e OmniDB ricorda il permesso, così ogni successiva connessione PostgreSQL cerca lì la propria password, proprio come farebbe psql. Importa connessioni da .pgpass… nella sezione Connessioni concede lo stesso accesso. Vedi Creazione di utenti e connessioni.
