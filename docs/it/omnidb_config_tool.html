Strumento di configurazione OmniDB

Nota: l’utility CLI standalone omnidb-config/omnidb-config-app/ omnidb-config-server descritta in questa pagina apparteneva alla precedente versione basata su Python/Django e non fa parte della release attuale. Il singolo binario omnidb-server accetta solo -A/--app (modalità app desktop) e -d/--homedir (scelta della directory home), documentati nel capitolo Installazione. Le attività di manutenzione che il vecchio strumento offriva possono ancora essere svolte manualmente, come descritto di seguito.

Directory home

OmniDB memorizza tutto — il database omnidb.db (utenti, connessioni e altri dati dell’app) e una cartella temp per i file esportati — in un’unica directory home. Per impostazione predefinita è ~/.omnidb/omnidb-app (modalità desktop) o ~/.omnidb/omnidb-server (modalità server); passa -d /percorso/qualsiasi per usarne una diversa.

Creare un utente

Attualmente non esiste un’opzione da riga di comando per creare un utente senza aprire OmniDB. Alla prima esecuzione con una directory home vuota, OmniDB crea automaticamente un superuser predefinito admin/admin — accedi con questo utente e crea altri utenti dalla schermata Utenti, oppure cambia la password predefinita.

Vacuum

OmniDB ha un unico database SQLite, omnidb.db, che memorizza tutti gli utenti, le connessioni e altri dati relativi a OmniDB. Trattandosi di un semplice file SQLite, puoi eseguirne il vacuum con qualsiasi client SQLite mentre OmniDB non è in esecuzione, ad esempio:

user@machine:~$ sqlite3 ~/.omnidb/omnidb-app/omnidb.db 'VACUUM;'

Reimpostare il database

Se desideri eliminare tutte le informazioni di OmniDB e ottenere un database pulito come appena installato, chiudi OmniDB ed elimina (o sposta altrove) il file omnidb.db nella directory home. Un nuovo file vuoto — con un nuovo utente predefinito admin/admin — viene creato automaticamente al successivo avvio di OmniDB. Usa questa procedura con cautela: non può essere annullata.

Eliminare i file temporanei

I risultati delle query esportati (CSV/XLSX/ecc.) vengono scritti nella cartella temp all’interno della directory home. È sicuro eliminarne il contenuto manualmente in qualsiasi momento mentre OmniDB non è in esecuzione; OmniDB la ricrea quando necessario.
