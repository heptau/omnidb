Gestione dei database

Dopo aver creato una connessione puoi selezionarla facendo clic sull’azione Seleziona Connessione nella griglia delle connessioni. Vedrai che la connessione sarà rappresentata da una specie di scheda esterna chiamata Scheda di Connessione. E l’intera area viene chiamata Finestra di Lavoro.

Sezioni della finestra Workspace

Questa interfaccia ha diversi elementi:

  • 1) Connessioni: Apre un popup con la griglia delle Connessioni
  • 2) Schede Esterne: OmniDB ti permette di lavorare con più database contemporaneamente. Ogni database sarà accessibile tramite una scheda esterna. Le schede esterne possono anche ospitare funzionalità varie indipendenti dalla connessione, come la funzionalità Snippets
  • 3) Opzioni: Mostra l’utente attualmente connesso e, se l’utente è un superuser, mostra anche un link per la gestione utenti. Mostra anche i link per impostazioni utente, plugin installati, cronologia query, informazioni e logout.

Scheda Esterna di Connessione

La scheda esterna chiamata PostgreSQL – testdb ha questo nome a causa dell’alias (PostgreSQL) che abbiamo assegnato alla connessione verso il database testdb. Questa scheda è una Scheda Esterna di Connessione. Nota la piccola scheda con una croce accanto alla scheda esterna PostgreSQL - testdb. Questa permette di creare una nuova scheda esterna che sarà automaticamente una Scheda Esterna di Connessione. Tuttavia, la Scheda Esterna Snippet è fissa e sarà sempre la prima.

Una nuova Scheda Esterna di Connessione punterà sempre automaticamente alla prima connessione nella tua lista di connessioni al database. Oppure, se hai fatto clic sull’azione Seleziona Connessione, punterà alla connessione selezionata. Osserva gli elementi all’interno di questa scheda:

  • 1) Selettore di Connessione: Mostra tutte le connessioni e permette all’utente di selezionare quella corrente
  • 2) Albero delle Strutture: Mostra un albero gerarchico in cui puoi navigare tra gli elementi del database
  • 3) Pannelli Proprietà e DDL: Mostrano le Proprietà e il DDL relativi al nodo attualmente selezionato nell’albero
  • 4) Schede Interne: Permettono all’utente di eseguire azioni nel database corrente. Esistono diversi tipi di schede interne per il database corrente. Facendo clic sull’ultima piccola scheda con una croce, puoi aggiungere una nuova scheda. Una nuova scheda può essere una Scheda Query, Scheda Console, Dashboard di Monitoraggio o Backends

  • 5) Contenuto della Scheda Interna: Può variare a seconda del tipo di scheda interna. La figura mostra una Scheda Query e in questo caso il contenuto sarà un Editor SQL, con evidenziazione della sintassi, autocompletamento e trova & sostituisci
  • 6) Azioni della Scheda Interna: Possono variare a seconda del tipo di scheda interna. Per una Scheda Query, sono Esegui, Indenta SQL, Cronologia Comandi, Spiega, Spiega ed Esegui, Autocommit ed Esporta Dati
  • 7) Risultati della Scheda Interna: Una Scheda Query, dopo aver fatto clic sul Pulsante Esegui o digitato la scorciatoia di esecuzione (Alt-Q), mostrerà una griglia con i risultati della query nella sottoscheda Dati. Se la query chiama una funzione che genera messaggi, questi saranno mostrati nella sottoscheda Messaggi. Se invece di Esegui hai fatto clic su Spiega o Spiega ed Esegui, il piano di esecuzione della query sarà mostrato nella sottoscheda Spiega.

Lavorare con i database

Dai un’occhiata al selettore delle connessioni. OmniDB punta sempre alla prima connessione disponibile, ma puoi cambiarla facendo clic sul selettore.

Seleziona la connessione PostgreSQL. Ora vai all’albero appena sotto il selettore e fai clic per espandere il nodo radice PostgreSQL.

Tieni presente che ogni 30 minuti trascorsi senza eseguire azioni sul database farà comparire un popup di Autenticazione, poiché la password che OmniDB ha cifrato e mantenuto in memoria è ormai scaduta. Come spiegato in precedenza, questo è importante per la sicurezza del tuo database. Dopo aver digitato la password corretta, vedrai che il nodo PostgreSQL ora mostra la versione di PostgreSQL e che è stato espanso, mostrando la connessione al database corrente e anche gli elementi a livello di istanza: Database, Tablespace, Ruoli e Slot di Replica.

Puoi connetterti a un singolo database PostgreSQL e, usando la stessa connessione, puoi collegarti ad altri database nella stessa istanza PostgreSQL. Il database attualmente attivo sarà indicato sotto il selettore di connessione.

Per connetterti a un database diverso, espandi il nodo corrispondente a quel database. Apparirà un popup che chiede se vuoi davvero cambiare il database attivo.

Fai clic su Sì e OmniDB cambierà il database attivo con quello scelto. Ciò sarà riflesso nell’indicatore Database attivo e anche nel nome della scheda esterna.

Vai avanti ed espandi il nodo Schemi. Vedrai tutti gli schemi presenti nel database corrente (nel caso di PostgreSQL, gli schemi TOAST e temporanei non sono mostrati).

Ora fai clic per espandere lo schema public. Vedrai diversi tipi di elementi contenuti in questo schema.

Ora fai clic per espandere il nodo Tabelle, e vedrai tutte le tabelle contenute nello schema public. Espandi una qualsiasi tabella e vedrai le sue colonne, chiave primaria, chiavi esterne, vincoli, indici, regole, trigger e partizioni.

Per visualizzare i record all’interno di una tabella, fai clic destro su di essa e scegli *Azioni sui Dati

Interroga Dati*.

Nota che OmniDB apre un nuovo editor SQL con una semplice query per elencare i record della tabella. I record vengono visualizzati in una griglia subito sotto l’editor. Questa griglia può essere controllata da tastiera come se stessi usando un foglio di calcolo. Puoi anche copiare dati da singole celle o blocchi di celle (selezionabili con tastiera o mouse) e incollarli in qualsiasi foglio di calcolo.

Puoi modificare la query nell’editor SQL, scrivendo query semplici o più complesse. Per eseguirla, fai clic sul pulsante di azione o premi la combinazione di tasti Alt-Q. Se i risultati superano i 100 record, compariranno i pulsanti aggiuntivi Carica Altri e Carica Tutti. Maggiori dettagli nei capitoli successivi.

Lavorare con più schede all’interno della stessa connessione

All’interno di una singola connessione, puoi creare più schede query interne facendo clic sull’ultima piccola scheda con una croce, e poi scegliendo Scheda Query.

Su OmniDB puoi eseguire più istruzioni SQL e procedure in parallelo. Durante l’esecuzione, un’icona verrà mostrata nella scheda per indicarne lo stato attuale. Se un processo è terminato e non si trova nella scheda corrente, quella scheda mostrerà un’icona verde che indica che la routine eseguita lì è ora terminata.

Facendo clic sul pulsante Annulla, puoi annullare un processo in esecuzione all’interno del database.

Puoi anche trascinare e rilasciare una scheda per cambiarne l’ordine. Questo funziona sia per le schede interne che per quelle esterne.

Inoltre, puoi usare scorciatoie da tastiera per gestire le schede interne (Query SQL). Queste sono le impostazioni predefinite su Windows/Linux (su macOS Ctrl sostituisce Alt); tutte possono essere riassegnate nella scheda Scorciatoie della finestra di dialogo Impostazioni:

  • Alt-I: Inserisce una nuova scheda interna
  • Alt-Shift-Q: Rimuove la scheda interna corrente
  • Alt-O: Sposta il focus sulla scheda interna a sinistra
  • Alt-P: Sposta il focus sulla scheda interna a destra

Attualmente non esistono scorciatoie da tastiera per le schede esterne (Connessione) — per queste usa il trascinamento con il mouse per riordinarle.

Tutte le schede Query SQL vengono salvate automaticamente ogni volta che le esegui. Anche se chiudi la finestra di OmniDB o la scheda del browser, sono già memorizzate nel Database Utente di OmniDB. Verranno ripristinate automaticamente quando riapri OmniDB (se usi l’app), lo apri in un’altra finestra del browser (se usi il server), o anche se hai fatto clic sulla finestra Connessioni o hai effettuato il logout. Rimuovere una scheda esterna o interna dall’interfaccia la elimina permanentemente, quindi non verrà ripristinata.
