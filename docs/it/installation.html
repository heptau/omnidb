Installazione

OmniDB offre 2 tipi di pacchetti per soddisfare le esigenze di ogni utente:

  • OmniDB Application: Esegue un server web su una porta casuale in background e fornisce una finestra del browser semplificata per utilizzare l’interfaccia di OmniDB senza alcuna configurazione aggiuntiva. Sembra semplicemente un’applicazione desktop.
  • OmniDB Server: Esegue un server web su una porta casuale, o su una porta specificata dall’utente. L’utente deve connettersi tramite un browser web. Fornisce la gestione degli utenti, ideale per essere ospitato su un server nella rete degli utenti.

Sia l’applicazione che il server possono essere installati sulla stessa macchina.

OmniDB Application

Importante: Il repository originale https://github.com/OmniDB/OmniDB/releases contiene solo versioni vecchie (fino al ~2020) e non è più mantenuto — vedi Funzionalità legacy e cronologia per cosa è cambiato da allora.

Per le versioni attuali usa la pagina delle release del progetto ripreso. Dalla riscrittura in Go, ogni release è un singolo archivio auto-contenuto per piattaforma — nessun installer, nessun runtime separato da installare prima:

  • macOS (Apple Silicon o Intel): OmniDB-macOS-osx-arm64.zip / OmniDB-macOS-osx-x64.zip
  • Linux x64: OmniDB-linux-x64.tar.gz
  • Windows x64: OmniDB-win-x64.zip

Decomprimi l’archivio per la tua piattaforma ed esegui l’app/binario OmniDB — questa è l’intera installazione. Le build per Linux e Windows sono prodotte dalla CI per ogni release ma non sono ancora state verificate su hardware reale, a differenza della build macOS; se incontri un problema specifico di piattaforma, apri una segnalazione.

Installazione tramite Homebrew (solo macOS – consigliato)

Per gli utenti macOS che preferiscono un gestore di pacchetti, OmniDB è disponibile tramite un tap Homebrew personalizzato:

# Installa l'ultima versione:
brew install --cask heptau/tap/omnidb
# Per aggiornare in seguito:
brew upgrade heptau/tap/omnidb

Homebrew scaricherà automaticamente lo ZIP corretto per la tua architettura (Apple Silicon o Intel), lo decomprimerà e posizionerà OmniDB.app nella cartella Applicazioni.

La definizione del cask è mantenuta qui: heptau/homebrew-tap – omnidb.rb

Download diretto (tutte le piattaforme)

  • macOS (Apple Silicon)
  • macOS (Intel)
  • Linux (x64)
  • Windows (x64)

Questi link puntano sempre all'ultima versione. Per le versioni precedenti, i checksum e le note di rilascio, consulta la pagina delle release.

Decomprimi l’archivio per la tua piattaforma e avvia l’app nel modo normale: su macOS, trascina OmniDB.app in Applicazioni e aprilo da Launchpad/Spotlight o con open -a OmniDB; su Linux, esegui il binario OmniDB direttamente; su Windows, esegui OmniDB.exe.

OmniDB Server

Lo stesso archivio della release contiene anche omnidb-server — un binario headless separato insieme all’app desktop (l’app desktop in realtà avvia internamente questo stesso binario come processo figlio, forzando la modalità app). Eseguito direttamente per la modalità server accessibile dal browser, senza shell desktop:

user@machine:~$ ./omnidb-server
omnidb-server: listening on 127.0.0.1:52149 — open http://127.0.0.1:52149/omnidb_login/ in your browser

Di default OmniDB ascolta solo su 127.0.0.1 e sceglie una porta libera automaticamente. Puoi specificare entrambi esplicitamente:

user@machine:~$ ./omnidb-server -p 8080 -H 0.0.0.0
omnidb-server: listening on 0.0.0.0:8080 — open http://0.0.0.0:8080/omnidb_login/ in your browser

Vedi Distribuzione di omnidb-server per l’insieme completo di opzioni e le configurazioni di deployment consigliate (in particolare, perché esporre -H 0.0.0.0 direttamente su internet senza un reverse proxy è sconsigliato — non c’è supporto TLS integrato).

OmniDB con Oracle

Né l’app OmniDB né il server richiedono software aggiuntivo per connettersi a Oracle — a differenza delle versioni precedenti, non è necessaria l’installazione separata di Oracle Instant Client. La connettività Oracle è implementata nativamente (un driver Go puro), quindi funziona allo stesso modo, immediatamente, come ogni altro database supportato.

Database Utente OmniDB

Al primo avvio, sia il server che l’app creano un file ~/.omnidb/omnidb-app/omnidb.db (per OmniDB app) o ~/.omnidb/omnidb-server/omnidb.db (per OmniDB server) nella home directory dell’utente, se non esiste già — insieme a un account superutente di default admin/admin, pronto per l’accesso immediato. Questo file è anche chiamato database utente e contiene tutti gli utenti, le connessioni e altri dati dell’applicazione. Se esiste già (ad esempio dopo un aggiornamento), OmniDB lo utilizza così com’è — non viene mai sovrascritto o resettato automaticamente.
