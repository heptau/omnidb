Gestione di altri elementi

Tutte le strutture PostgreSQL possono essere gestite tramite l'uso di modelli SQL. Questo offre all'utente maggiore controllo rispetto all'uso di form grafici per manipolare le strutture.

Ad esempio, consideriamo le sequenze all'interno dello schema public del database ds2. Per creare una nuova sequenza, fai clic destro sul nodo Sequenze e scegli Crea Sequenza.

Dopo aver cambiato il nome della sequenza, puoi decommentare altre opzioni del comando e impostarle secondo le tue necessità. Quando l'intero comando ti sembra corretto, eseguilo e la nuova sequenza verrà creata:

Facendo clic destro su una sequenza esistente, puoi modificarla o eliminarla. Funzionerà allo stesso modo della creazione, usando un modello SQL che l'utente può modificare.
