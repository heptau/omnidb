Replicação Lógica

O PostgreSQL 10 introduz a replicação lógica nativa, que usa um modelo de publicação/subscrição, permitindo-nos criar publicações no nó a montante (ou publicador) e subscrições no nó a jusante (ou subscritor). Para mais detalhes sobre este tema, consulte a documentação do PostgreSQL.

Neste capítulo, vamos usar um cluster de 2 nós para demonstrar a replicação lógica nativa do PostgreSQL 10. Note que, em cada instância do PostgreSQL, precisa de configurar wal_level = logical e também certificar-se de que ajusta o ficheiro pg_hba.conf para conceder acesso de replication entre os 2 nós.

Criar um ambiente de teste

Configure duas instâncias PostgreSQL 10+ da forma que preferir (Docker, uma máquina virtual, ou até mesmo duas bases de dados na mesma máquina) e configure as definições acima em cada uma.

Em ambos os nós, crie uma tabela como esta:
