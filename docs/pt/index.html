Renascimento do Projeto OmniDB

A ferramenta de gestão de bases de dados leve, poderosa e open source está de volta para potenciar os fluxos de trabalho de desenvolvimento modernos.

Ativamente relançado pelos criadores do PgArachne — unindo uma administração robusta de bases de dados com arquiteturas modernas de cliente leve.

Arraste a pega — o mesmo espaço de trabalho, claro ou escuro.

Escuro Claro

Instalar o OmniDB

🍺

Homebrew macOS

Recomendado para macOS — o cask deteta automaticamente Apple Silicon ou Intel.

brew install --cask heptau/tap/omnidb
⬇️

GitHub Releases macOS · Linux · Windows

Descarregue o arquivo autónomo para a sua plataforma — sem instalador, sem runtime separado.

Última Versão →

Instruções completas de instalação: → Guia Detalhado de Instalação

O macOS está verificado de ponta a ponta; as compilações para Linux e Windows saem do mesmo pipeline de CI, mas ainda não foram verificadas em hardware real. Versões mais antigas (até cerca de 2020) do repositório original já não são mantidas.

Porquê o OmniDB?

⚡

Reescrito para Velocidade

Python → Go. As consultas são executadas e a interface responde sem um interpretador pelo caminho.

📦

Binário Leve

A antiga shell Electron/NW.js desapareceu. O Wails agora conduz a aplicação através do webview nativo do sistema operativo.

🖥️

Todas as Plataformas, um Único Lançamento

macOS (Apple Silicon e Intel), Linux e Windows são compilados e distribuídos a partir do mesmo lançamento.

🗄️

Cinco Motores, um Único Espaço de Trabalho

PostgreSQL, MySQL, MariaDB, Oracle e SQLite num único espaço de trabalho com separadores.

🔒

Ativamente Reforçado

Correções reais — SQL injection, XSS, IDOR — surgem continuamente. Veja o changelog.

📤

Exportar para Qualquer Lugar

Diretamente para CSV, XLSX, TSV, Markdown, JSON ou XML.
