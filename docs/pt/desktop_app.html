Aplicação de Ambiente de Trabalho

A aplicação de ambiente de trabalho (OmniDB.app no macOS, OmniDB/OmniDB.exe no Linux e no Windows) é uma pequena janela nativa em torno da mesma interface do OmniDB que a versão servidor serve aos browsers. Inicia a sua própria cópia privada do omnidb-server em segundo plano, a escutar apenas na máquina local, e inicia sessão automaticamente como o utilizador incorporado admin — não há página de início de sessão, nem ícone Conta, nem nada para configurar. Consulte Instalação para saber como obtê-la.

Onde ficam os dados

As ligações guardadas, snippets, definições, histórico de consultas, etc. são mantidos em ~/.omnidb/omnidb-app/ (a base de dados de utilizador omnidb.db, mais uma pasta temp para exportações e a posição guardada da janela). Para manter um conjunto de dados separado — por exemplo, um descartável para testes — inicie a aplicação com uma pasta pessoal diferente:

open -a OmniDB --args -d /path/to/other/dir    # macOS
./OmniDB -d /path/to/other/dir                  # Linux
OmniDB.exe -d C:\path\to\other\dir              # Windows

A pasta já tem de existir; uma pasta nova e vazia é preparada automaticamente na primeira utilização. As palavras-passe guardadas são encriptadas com uma chave mantida no armazenamento de segredos do sistema operativo — consulte Segurança e Servidor Multiutilizador.

A barra de menus

  • OmniDB: Sobre o OmniDB, Preferências… (Cmd/Ctrl-,), Importar dados da instalação anterior… (apenas na versão macOS em sandbox, ver abaixo) e Sair do OmniDB (Cmd/Ctrl-Q).
  • Edit e Window: os menus padrão do sistema operativo (anular/cortar/copiar/colar, minimizar, zoom, ecrã inteiro, …).
  • Visualizar: salta para uma secção da barra esquerda — Bem-vindo (Cmd/Ctrl-Shift-W), Conexões (Cmd/Ctrl-Shift-C), Banco de Dados (Cmd/Ctrl-Shift-D), Notificações (Cmd/Ctrl-Shift-N), Utilizadores ligados (Cmd/Ctrl-Shift-U), Snippets (Cmd/Ctrl-Shift-S) — e ainda Alternar árvore do banco de dados (Cmd/Ctrl-B) e Alternar painel de propriedades/DDL (Cmd/Ctrl-Shift-B).
  • Ajuda: Primeiros Passos (o tutorial interativo), Atalhos de Teclado (abre as Definições na categoria Atalhos de teclado), Visitar omnidb.net e Repositório no GitHub.

Os menus OmniDB, Visualizar e Ajuda são mostrados no idioma escolhido em Definições > Aparência > Idioma e mudam assim que o alterar; antes de a primeira página ser carregada, seguem o idioma do sistema operativo. Os menus padrão Edit e Window permanecem em inglês. O título da janela mostra a secção em que se encontra (por exemplo OmniDB - Snippets).

Tamanho e posição da janela

No primeiro arranque, a janela abre maximizada. A partir daí, reabre com o tamanho, a posição e o estado maximizado/restaurado que tinha quando a fechou pela última vez.

Links e ficheiros

Os links para páginas externas (as entradas Doc: … da árvore da base de dados, os links da página de Boas-vindas, o menu Ajuda) abrem no seu browser predefinido. As exportações e Exportar como DBML abrem o diálogo nativo Guardar como, pelo que escolhe diretamente para onde vai o ficheiro — consulte Escrever Consultas SQL.

macOS: sandbox, dados anteriores e .pgpass

A aplicação macOS é executada na App Sandbox, que lhe dá a sua própria pasta pessoal privada. Daí resultam duas consequências:

  • Os dados de uma instalação anterior sem sandbox em ~/.omnidb não ficam visíveis automaticamente. No primeiro arranque sem quaisquer dados, o OmniDB propõe importá-los — escolha Import… e selecione a sua pasta .omnidb anterior, ou Not Now. Pode fazer o mesmo mais tarde com OmniDB > Importar dados da instalação anterior….
  • ~/.pgpass não pode ser lido até o autorizar. Quando uma ligação PostgreSQL não tem palavra-passe guardada, a caixa da palavra-passe oferece Conceder acesso ao .pgpass…: selecione o seu ficheiro .pgpass uma vez (os ficheiros ocultos são mostrados nesse diálogo) e o OmniDB memoriza a permissão, pelo que todas as ligações PostgreSQL seguintes procuram aí a sua palavra-passe, tal como o psql faria. Importar ligações de .pgpass… na secção Ligações concede o mesmo acesso. Consulte Criar Utilizadores e Ligações.
