Ferramenta de Configuração do OmniDB

Nota: o utilitário de linha de comandos autónomo omnidb-config/omnidb-config-app/ omnidb-config-server descrito nesta página pertencia à versão anterior baseada em Python/Django e não faz parte do lançamento atual. O binário único omnidb-server apenas aceita -A/--app (modo aplicação de ambiente de trabalho) e -d/--homedir (escolher a pasta pessoal), documentados no capítulo Instalação. As tarefas de manutenção que a ferramenta antiga oferecia ainda podem ser feitas manualmente, como descrito abaixo.

Pasta pessoal

O OmniDB armazena tudo — a base de dados omnidb.db (utilizadores, ligações e outros dados da aplicação) e uma pasta temp para ficheiros exportados — numa única pasta pessoal. Por predefinição, esta é ~/.omnidb/omnidb-app (modo aplicação de ambiente de trabalho) ou ~/.omnidb/omnidb-server (modo servidor); passe -d /some/path para usar uma pasta diferente.

Criar um utilizador

Atualmente não existe nenhuma opção de linha de comandos para criar um utilizador sem abrir o OmniDB. Na primeira execução com uma pasta pessoal vazia, o OmniDB cria automaticamente um superutilizador predefinido admin/admin — inicie sessão com ele e crie outros utilizadores a partir do ecrã Users, ou altere a palavra-passe predefinida.

Compactar (Vacuum)

O OmniDB tem uma única base de dados SQLite, omnidb.db, que armazena todos os utilizadores, ligações e outros dados relacionados com o OmniDB. Como se trata de um simples ficheiro SQLite, pode compactá-lo com qualquer cliente SQLite enquanto o OmniDB não estiver em execução, por exemplo:

user@machine:~$ sqlite3 ~/.omnidb/omnidb-app/omnidb.db 'VACUUM;'

Repor a base de dados

Se quiser eliminar todas as informações do OmniDB e obter uma base de dados limpa, como acabada de instalar, saia do OmniDB e elimine (ou mova para outro local) o ficheiro omnidb.db da pasta pessoal. Um novo ficheiro vazio — com um novo utilizador predefinido admin/admin — é criado automaticamente da próxima vez que o OmniDB arrancar. Use isto com cuidado: não pode ser desfeito.

Eliminar ficheiros temporários

Os resultados de consultas exportados (CSV/XLSX/etc.) são escritos na pasta temp dentro da pasta pessoal. É seguro eliminar o seu conteúdo manualmente a qualquer momento enquanto o OmniDB não estiver em execução; o OmniDB recria-a conforme necessário.
