Visualizar Planos de Consulta

O OmniDB tem uma funcionalidade muito útil: visualização gráfica de planos de consulta. Isto pode ser muito prático ao escrever ou otimizar consultas, uma vez que permite identificar facilmente problemas de desempenho na sua consulta SQL.

Para esta funcionalidade, o separador interior SQL Query mostra 2 botões: Explain e Explain Analyze.

Visualização textual

Quando clica no botão Explain, o OmniDB executa um comando EXPLAIN na sua consulta. A visualização inicial é textual e mostrará exatamente o resultado do comando EXPLAIN, mas com barras coloridas representando o custo estimado. Quanto maior o custo, mais escura e larga é a barra.

Quando clica no botão Explain Analyze, o OmniDB executa um comando EXPLAIN ANALYZE na sua consulta. Tenha em atenção que este comando executa realmente a consulta. Além disso, a visualização textual mostrará muito mais informação, e os custos não são estimados como os fornecidos pelo comando EXPLAIN; são custos reais.

Visualização em árvore

Tanto o modo Explain como o Explain Analyze também podem representar graficamente a saída textual num diagrama em árvore. Cada círculo representa um nó executado pelo plano de consulta, e quanto maior o círculo, maior o custo.
