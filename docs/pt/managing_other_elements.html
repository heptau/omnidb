Gerir Outros Elementos

Todas as estruturas do PostgreSQL podem ser geridas com o uso de modelos SQL. Isto dá ao utilizador mais poder do que usar formulários gráficos para manipular estruturas.

Por exemplo, consideremos as sequências dentro do esquema public da base de dados ds2. Para criar uma nova sequência, clique com o botão direito no nó Sequences, e escolha Create Sequence (Criar Sequência).

Depois de alterar o nome da sequência, pode descomentar outras opções de comando e defini-las de acordo com as suas necessidades. Quando o comando completo parecer correto, basta executá-lo e a nova sequência será criada:

Com um clique com o botão direito numa sequência existente, pode alterá-la ou eliminá-la. Funcionará da mesma forma que a criação, usando um modelo SQL para o utilizador alterar.
