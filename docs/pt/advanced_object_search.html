Pesquisa Avançada de Objetos

Nota: esta funcionalidade não está disponível na versão atual. A sua entrada no menu de árvore está comentada, e as funções de frontend e o gestor de backend em Go de que dependia já não existem — não foi transportada durante a reescrita em Go, e reativá-la significaria construí-la de novo em vez de apenas ligar um interruptor. O resto deste capítulo mantém-se como descrição de como funcionava anteriormente, para referência histórica.

A Pesquisa Avançada de Objetos permitia aos utilizadores aplicar correspondência de padrões para pesquisar objetos de base de dados e dados de tabelas — o operador SQL LIKE predefinido, ou expressões regulares complexas.

Podia aceder-se à funcionalidade de Pesquisa Avançada de Objetos clicando com o botão direito num nó de base de dados específico na árvore:

A interface permitia filtrar categorias de objetos, esquemas onde as pesquisas seriam executadas, e também limitar o espaço de pesquisa quando a categoria Data estava selecionada, para que se pudesse pesquisar um padrão num subconjunto de tabelas:

Depois de preencher os campos e executar, o OmniDB efetuava a pesquisa usando várias threads que aceleravam o processo ao executar em paralelo (era personalizável; para mais informação, consulte Implementar o omnidb-server).
