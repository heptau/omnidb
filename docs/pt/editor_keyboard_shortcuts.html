Atalhos de Teclado do Editor

O editor SQL, o editor de Consola e o visualizador de DDL/Propriedades do OmniDB assentam todos sobre o editor de código Ace, que vem com o seu próprio e rico conjunto de atalhos de teclado para editar, selecionar e navegar no texto. Este capítulo lista-os como referência. Estes atalhos são independentes dos atalhos próprios do OmniDB ao nível da aplicação (Executar Consulta, Cancelar Consulta, alternar entre separadores, etc.), que se encontram no separador Atalhos da caixa de diálogo Definições e podem ser reatribuídos a partir daí — consulte Funcionalidades Adicionais para saber como o abrir.
