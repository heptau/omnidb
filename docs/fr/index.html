Renaissance du projet OmniDB

L’outil de gestion de bases de données léger, puissant et open source est de retour pour accompagner les workflows de développement modernes.

Activement relancé par les créateurs de PgArachne — alliant une administration de bases de données robuste à des architectures client léger modernes.

Faites glisser le curseur — même espace de travail, en clair ou en sombre.

Installer OmniDB

🍺

Homebrew macOS

Recommandé pour macOS — le cask détecte automatiquement Apple Silicon ou Intel.

brew install --cask heptau/tap/omnidb
⬇️

GitHub Releases macOS · Linux · Windows

Téléchargez l’archive autonome pour votre plateforme — sans installateur, sans runtime séparé.

Dernière version →

Instructions d’installation complètes : → Guide d’installation détaillé

macOS est vérifié de bout en bout ; les versions Linux et Windows proviennent du même pipeline CI mais n’ont pas encore été vérifiées sur du matériel réel. Les anciennes versions (jusqu’à ~2020) du dépôt d’origine ne sont plus maintenues.

Pourquoi OmniDB ?

⚡

Réécrit pour la vitesse

Python → Go. Les requêtes s’exécutent et l’interface répond sans qu’un interpréteur ne s’interpose.

📦

Binaire ultraléger

L’ancienne coque Electron/NW.js a disparu. Wails pilote désormais l’application via le webview natif du système d’exploitation.

🖥️

Toutes les plateformes, une seule version

macOS (Apple Silicon et Intel), Linux et Windows sont construits et livrés depuis la même version.

🗄️

Cinq moteurs, un seul espace de travail

PostgreSQL, MySQL, MariaDB, Oracle et SQLite dans un même espace de travail à onglets.

🔒

Activement sécurisé

De vraies corrections — injections SQL, XSS, IDOR — arrivent en continu. Consultez le changelog.

📤

Exportez n’importe où

Directement en CSV, XLSX, TSV, Markdown, JSON ou XML.
