Gérer les autres éléments

Toutes les structures PostgreSQL peuvent être gérées à l’aide de modèles SQL. Cela offre à l’utilisateur davantage de puissance que l’utilisation de formulaires graphiques pour manipuler les structures.

Prenons par exemple les séquences du schéma public de la base de données ds2. Pour créer une nouvelle séquence, faites un clic droit sur le nœud Sequences (Séquences), et choisissez Create Sequence (Créer une séquence).

Après avoir changé le nom de la séquence, vous pouvez décommenter d’autres options de la commande et les définir selon vos besoins. Lorsque la commande complète vous convient, il suffit de l’exécuter et la nouvelle séquence sera créée :

Par un clic droit sur une séquence existante, vous pouvez la modifier ou la supprimer. Cela fonctionne de la même manière que la création, en utilisant un modèle SQL que l’utilisateur peut modifier.
