Visualiser les données

Cette fonctionnalité affiche un graphe avec des nœuds représentant les tables et des arêtes représentant les relations entre tables via les clés étrangères. À l'aide de la souris, l'utilisateur peut zoomer, dézoomer, et glisser-déposer les nœuds pour modifier leur position.

Il existe deux types de graphes : Simple Graph (Graphe simple) et Complete Graph (Graphe complet).

Graphe simple

Celui-ci affiche des nœuds de table simples et leurs relations. Pour y accéder, faites simplement un clic droit sur le nœud de schéma souhaité dans l'arborescence, puis sélectionnez l'action Render Graph > Simple Graph (Générer un graphe > Graphe simple) :

Graphe complet

Ce graphe affiche les tables avec toutes leurs colonnes et les types de données correspondants. Pour y accéder, faites simplement un clic droit sur le schéma souhaité dans l'arborescence, puis sélectionnez l'action Render Graph > Complete Graph (Générer un graphe > Graphe complet) :
