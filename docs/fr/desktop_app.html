Application de bureau

L’application de bureau (OmniDB.app sur macOS, OmniDB/OmniDB.exe sur Linux et Windows) est une petite fenêtre native autour de la même interface OmniDB que la version serveur propose aux navigateurs. Elle démarre en arrière-plan sa propre copie privée d’omnidb-server, qui n’écoute que sur la machine locale, et vous connecte automatiquement en tant qu’utilisateur intégré admin — il n’y a ni page de connexion, ni icône Compte, ni rien à configurer. Consultez Installation pour savoir comment l’obtenir.

Où sont stockées les données

Les connexions enregistrées, les extraits, les paramètres, l’historique des requêtes, etc. sont conservés dans ~/.omnidb/omnidb-app/ (la base de données utilisateur omnidb.db, plus un dossier temp pour les exports et la position enregistrée de la fenêtre). Pour conserver un jeu de données distinct — par exemple un jeu jetable pour des tests — lancez l’application avec un autre répertoire personnel :

open -a OmniDB --args -d /path/to/other/dir    # macOS
./OmniDB -d /path/to/other/dir                  # Linux
OmniDB.exe -d C:\path\to\other\dir              # Windows

Le répertoire doit déjà exister ; un répertoire nouveau et vide est initialisé automatiquement lors de sa première utilisation. Les mots de passe enregistrés sont chiffrés avec une clé conservée dans le magasin de secrets du système d’exploitation — voir Sécurité et serveur multi-utilisateur.

La barre de menus

  • OmniDB : À propos d’OmniDB, Préférences… (Cmd/Ctrl-,), Importer les données de l’installation précédente… (version macOS en sandbox uniquement, voir ci-dessous) et Quitter OmniDB (Cmd/Ctrl-Q).
  • Édition et Fenêtre : les menus standard du système d’exploitation (annuler/couper/copier/coller, placer dans le Dock, zoom, plein écran, …).
  • Affichage : accès direct à une section de la barre de navigation de gauche — Accueil (Cmd/Ctrl-Shift-W), Connexions (Cmd/Ctrl-Shift-C), Base de données (Cmd/Ctrl-Shift-D), Notifications (Cmd/Ctrl-Shift-N), Utilisateurs connectés (Cmd/Ctrl-Shift-U), Extraits (Cmd/Ctrl-Shift-S) — ainsi que Afficher/masquer l’arborescence de la base de données (Cmd/Ctrl-B) et Afficher/masquer le panneau propriétés/DDL (Cmd/Ctrl-Shift-B).
  • Aide : Prise en main (le tutoriel interactif), Raccourcis clavier (ouvre les paramètres sur la catégorie Raccourcis), Visiter omnidb.net et Dépôt GitHub.

Les menus OmniDB, Affichage et Aide s’affichent dans la langue choisie sous Paramètres > Apparence > Langue et changent dès que vous la modifiez ; avant le chargement de la première page, ils suivent la langue du système d’exploitation. Les menus standard Édition et Fenêtre restent en anglais. Le titre de la fenêtre indique la section dans laquelle vous vous trouvez (par exemple OmniDB - Extraits).

Taille et position de la fenêtre

Lors du tout premier lancement, la fenêtre s’ouvre agrandie. Ensuite, elle se rouvre avec la taille, la position et l’état agrandi/restauré qu’elle avait lors de sa dernière fermeture.

Liens et fichiers

Les liens vers des pages externes (les entrées Doc. : … de l’arborescence de la base de données, les liens de la page d’accueil, le menu Aide) s’ouvrent dans votre navigateur web par défaut. Les exports et Exporter en DBML ouvrent la boîte de dialogue native Enregistrer sous, pour que vous choisissiez directement l’emplacement du fichier — voir Écrire des requêtes SQL.

macOS : sandbox, données précédentes et .pgpass

L’application macOS s’exécute dans l’App Sandbox, qui lui attribue son propre dossier personnel privé. Deux conséquences :

  • Les données d’une installation antérieure, hors sandbox, situées dans ~/.omnidb ne sont pas visibles automatiquement. Au premier lancement sans aucune donnée, OmniDB propose de les importer — choisissez Import… et sélectionnez votre ancien dossier .omnidb, ou Not Now (Plus tard). Vous pouvez faire de même plus tard avec OmniDB > Importer les données de l’installation précédente….
  • ~/.pgpass n’est pas lisible tant que vous ne l’avez pas autorisé. Lorsqu’une connexion PostgreSQL n’a pas de mot de passe enregistré, la demande de mot de passe propose Accorder l’accès à .pgpass… : sélectionnez une fois votre fichier .pgpass (les fichiers masqués sont affichés dans cette boîte de dialogue) et OmniDB mémorise l’autorisation, de sorte que toutes les connexions PostgreSQL suivantes y recherchent leur mot de passe, exactement comme le ferait psql. Importer des connexions depuis .pgpass… dans la section Connexions accorde le même accès. Voir Créer des utilisateurs et des connexions.
