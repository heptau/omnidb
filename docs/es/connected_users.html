Usuarios conectados

La sección Usuarios conectados muestra quién está conectado ahora mismo a un servidor de base de datos (backends de PostgreSQL, hilos de MySQL/MariaDB, sesiones de Oracle y SQL Server, conexiones de Firebird), qué está haciendo cada uno y le permite terminar cualquiera de ellos. Sustituye a las antiguas entradas Backends/Process List/Sessions específicas de cada motor en el menú contextual del árbol de la base de datos.

Compatible con: PostgreSQL, MySQL, MariaDB, Oracle, SQL Server y Firebird. SQLite no tiene ese concepto y muestra Ver los usuarios conectados no es compatible con conexiones ….

Abrir la sección

Haga clic en el icono Usuarios conectados de la barra izquierda. Al igual que Monitorización, Notificaciones y Permisos, trabaja sobre una conexión ya abierta en la sección Base de datos: la franja de pestañas de conexión abiertas se muestra en la parte superior, y la lista pertenece a la pestaña seleccionada. Si no hay ninguna conexión abierta, muestra No hay ninguna conexión abierta.

La lista se carga al entrar en la sección y cada vez que cambia a otra pestaña de conexión; no se actualiza por sí sola. Para recargarla, haga clic derecho en la cuadrícula y elija Actualizar. El número de filas se muestra encima de la cuadrícula (Número de registros: …).

Columnas

Las columnas se agrupan de forma compacta (por ejemplo, un ID bajo un nombre, o la dirección y el puerto en una misma línea); al pasar el ratón sobre la cabecera de una columna se explica qué muestra y de qué columna del catálogo procede.

  • PostgreSQL (pg_stat_activity): PID, Base de datos, Usuario, Cliente, Aplicación, Inicio del proceso / Inicio de la transacción, Inicio de la consulta / Último cambio de estado, En espera de, Estado, ID de transacción, ID de consulta, Tipo de proceso.
  • MySQL/MariaDB (lista de procesos): Usuario (con el ID de conexión), Host, Base de datos, Comando, Tiempo (s), Estado.
  • Oracle (v$session): SID (con Serial#), Usuario, Estado, Esquema, Cliente, Programa, Módulo / acción, Info del cliente, Hora de inicio de sesión, Inactivo (s), ID de SQL, En espera de, SID bloqueante.
  • SQL Server (sesiones de usuario): ID de sesión, Nombre de inicio de sesión, Host, Programa, Estado.
  • Firebird (mon$attachments, sin la conexión propia de OmniDB): ID de conexión, Usuario, Dirección remota, Estado.

En PostgreSQL y Oracle, los procesos en segundo plano o del sistema están ocultos de forma predeterminada; marque Mostrar procesos del sistema encima de la cuadrícula para incluirlos (la casilla solo aparece cuando hay filas de ese tipo).

Ver la consulta de una sesión

En PostgreSQL, MySQL y MariaDB, al hacer clic en una fila se abre bajo la cuadrícula un panel Texto de la consulta con la sentencia que esa sesión está ejecutando (o ejecutó por última vez), con resaltado de sintaxis y de solo lectura. Desde allí puede copiarla o usar Abrir en una nueva pestaña de consulta para seguir trabajando con ella en una pestaña de consulta normal, por ejemplo para ejecutar Explain sobre ella.

Terminar una sesión

Haga clic derecho en una fila y elija Terminar. Tras su confirmación, OmniDB finaliza esa sesión de la forma propia de cada motor (pg_terminate_backend() en PostgreSQL, KILL en MySQL/MariaDB y SQL Server, ALTER SYSTEM KILL SESSION … IMMEDIATE en Oracle, borrando la fila de mon$attachments en Firebird) y recarga la lista. Para ello se necesita el privilegio correspondiente en el servidor de base de datos. El mismo menú contextual ofrece también Copiar y Ver contenido para la celda en la que se hizo clic.
