Administración de bases de datos

Tras crear una conexión, puede seleccionarla haciendo clic en la acción Select Connection (Seleccionar conexión) de la cuadrícula de conexiones. Verá que la conexión se representará mediante una especie de pestaña externa llamada pestaña de conexión (Connection Tab). Y toda esta área se denomina ventana de espacio de trabajo (Workspace Window).

Secciones de la ventana Workspace

Esta interfaz tiene varios elementos:

  • 1) Connections (Conexiones): abre una ventana emergente con la cuadrícula de Connections
  • 2) Outer Tabs (Pestañas externas): OmniDB permite trabajar con varias bases de datos al mismo tiempo. Cada base de datos será accesible a través de una pestaña externa. Las pestañas externas también pueden alojar funciones diversas independientes de la conexión, como la función Snippets
  • 3) Options (Opciones): muestra el usuario actualmente conectado y, si es superusuario, también muestra un enlace a la administración de usuarios. Además muestra enlaces a la configuración de usuario, los complementos instalados, el historial de consultas, información y cerrar sesión.

Pestaña externa de conexión

La pestaña externa llamada PostgreSQL — testdb tiene ese nombre por el alias (PostgreSQL) que asignamos en la conexión a la base de datos testdb. Esta pestaña es una pestaña externa de conexión (Connection Outer Tab). Observe la pequeña pestaña con una cruz junto a la pestaña externa PostgreSQL — testdb. Esta permite crear una nueva pestaña externa que automáticamente será una pestaña externa de conexión. Sin embargo, la pestaña externa Snippet es fija y siempre será la primera.

Una nueva pestaña externa de conexión siempre apuntará automáticamente a la primera conexión de su lista de conexiones de base de datos. O bien, si hizo clic en la acción Select Connection, apuntará a la conexión seleccionada. Observe los elementos dentro de esta pestaña:

  • 1) Connection Selector (Selector de conexión): muestra todas las conexiones y permite al usuario seleccionar la actual
  • 2) Tree of Structures (Árbol de estructuras): muestra un árbol jerárquico en el que puede navegar por los elementos de la base de datos
  • 3) Properties and DDL Panels (Paneles de propiedades y DDL): muestran las propiedades y el DDL del nodo actualmente seleccionado en la vista de árbol
  • 4) Inner Tabs (Pestañas internas): permiten al usuario ejecutar acciones en la base de datos actual. Existen varios tipos de pestañas internas para la base de datos actual. Al hacer clic en la última pequeña pestaña con una cruz, puede añadir una nueva pestaña. Una nueva pestaña puede ser una pestaña de consulta (Query Tab), una pestaña de consola (Console Tab), el panel de monitorización (Monitoring Dashboard) o Backends

  • 5) Inner Tab Content (Contenido de la pestaña interna): puede variar según el tipo de pestaña interna. La imagen muestra una pestaña de consulta, y en este caso el contenido será un editor SQL, con resaltado de sintaxis, autocompletado y función de buscar y reemplazar
  • 6) Inner Tab Actions (Acciones de la pestaña interna): pueden variar según el tipo de pestaña interna. Para una pestaña de consulta, son Run (Ejecutar), Indent SQL (Sangrar SQL), Command History (Historial de comandos), Explain, Explain Analyze, Autocommit y Export Data (Exportar datos)
  • 7) Inner Tab Results (Resultados de la pestaña interna): una pestaña de consulta, tras hacer clic en el botón Execute o pulsar el atajo de ejecución (Alt-Q), mostrará una cuadrícula con los resultados de la consulta en la subpestaña Data. Si la consulta invoca una función que genera mensajes, estos se mostrarán en la subpestaña Messages. Si en lugar de Run hizo clic en Explain o Explain Analyze, el plan de ejecución de la consulta se mostrará en la subpestaña Explain.

Trabajar con bases de datos

Observe el selector de conexiones. OmniDB siempre apunta a la primera conexión disponible, pero puede cambiarla haciendo clic en el selector.

Seleccione la conexión PostgreSQL. Ahora vaya al árbol situado justo debajo del selector y haga clic para expandir el nodo raíz PostgreSQL.

Tenga en cuenta que, cada 30 minutos que pase sin realizar acciones en la base de datos, aparecerá una ventana emergente de Authentication (Autenticación), lo que significa que la contraseña que OmniDB cifró y almacenó en memoria ha caducado. Como se explicó antes, esto es importante para la seguridad de su base de datos. Tras introducir la contraseña correcta, verá que el nodo PostgreSQL ahora muestra la versión de PostgreSQL y también se ha expandido, mostrando la conexión de base de datos actual y también los elementos de ámbito de instancia: Databases (Bases de datos), Tablespaces, Roles y Replication Slots (Slots de replicación).

Puede conectarse a una única base de datos PostgreSQL y, utilizando la misma conexión, conectarse a otras bases de datos de la misma instancia de PostgreSQL. La base de datos actualmente activa se indicará debajo del selector de conexión.

Para conectarse a una base de datos diferente, expanda el nodo correspondiente a esa base de datos. Aparecerá una ventana emergente preguntando si realmente desea cambiar la base de datos activa.

Haga clic en Yes (Sí) y OmniDB cambiará la base de datos activa por la que ha elegido. Esto se reflejará en el indicador Active database (Base de datos activa), y también en el nombre de la pestaña externa.

Ahora expanda el nodo Schemas (Esquemas). Verá todos los esquemas de la base de datos actual (en el caso de PostgreSQL, los esquemas TOAST y temporales no se muestran).

Ahora haga clic para expandir el esquema public. Verá los distintos tipos de elementos que contiene este esquema.

Ahora haga clic para expandir el nodo Tables (Tablas) y verá todas las tablas contenidas en el esquema public. Expanda cualquier tabla y verá sus columnas, clave primaria, claves foráneas, restricciones, índices, reglas, disparadores y particiones.

Para ver los registros dentro de una tabla, haga clic con el botón derecho sobre ella y elija *Data Actions

Query Data*.

Observe que OmniDB abre un nuevo editor SQL con una consulta sencilla para listar los registros de la tabla. Los registros se muestran en una cuadrícula justo debajo del editor. Esta cuadrícula puede controlarse con el teclado como si estuviera utilizando una hoja de cálculo. También puede copiar datos de celdas individuales o de un bloque de celdas (que se pueden seleccionar con el teclado o el ratón) y pegarlos en cualquier hoja de cálculo.

Puede editar la consulta en el editor SQL, escribiendo consultas simples o más complejas. Para ejecutarla, haga clic en el botón de acción o pulse el atajo Alt-Q. Si los resultados superan los 100 registros, aparecerán los botones adicionales Fetch More (Obtener más) y Fetch All (Obtener todo). Más detalles en los próximos capítulos.

Trabajar con varias pestañas dentro de la misma conexión

Dentro de una misma conexión, puede crear varias pestañas internas de consulta haciendo clic en la última pequeña pestaña con una cruz y eligiendo después Query Tab (Pestaña de consulta).

En OmniDB puede ejecutar varias sentencias SQL y procedimientos en paralelo. Mientras se están ejecutando, se mostrará un icono en la pestaña que indica su estado actual. Si un proceso finaliza y no se encuentra en la pestaña actual, esa pestaña mostrará un icono verde que indica que la rutina que se ejecutaba en ella ya ha finalizado.

Al hacer clic en el botón Cancel (Cancelar), puede cancelar un proceso en ejecución dentro de la base de datos.

También puede arrastrar y soltar una pestaña para cambiar su orden. Esto funciona tanto con pestañas internas como externas.

Además, puede usar atajos de teclado para administrar las pestañas internas (consulta SQL). Estos son los valores predeterminados en Windows/Linux (macOS sustituye Alt por Ctrl); todos ellos se pueden reasignar en la pestaña Atajos del diálogo de Configuración:

  • Alt-I: inserta una nueva pestaña interna
  • Alt-Shift-Q: elimina la pestaña interna actual
  • Alt-O: cambia el foco a la pestaña interna de la izquierda
  • Alt-P: cambia el foco a la pestaña interna de la derecha

Actualmente no existen atajos de teclado para las pestañas externas (de conexión); para ellas, use el reordenamiento por arrastrar y soltar, o el ratón.

Todas las pestañas de consulta SQL se guardan automáticamente cada vez que se ejecutan. Incluso si cierra la ventana de OmniDB o la pestaña del navegador, ya están almacenadas en la base de datos de usuario de OmniDB. Se restaurarán automáticamente al volver a abrir OmniDB (si usa la aplicación), al abrirla en otra ventana del navegador (si usa el servidor), o incluso si hizo clic en la ventana de Connections (Conexiones) o cerró sesión. Eliminar una pestaña externa o interna desde la interfaz la borra de forma permanente, por lo que no se restaurará.
