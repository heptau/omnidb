Administración de datos de tablas

La herramienta permite editar los registros contenidos en las tablas mediante una interfaz muy sencilla e intuitiva. Dado que solo unos pocos SGBD proporcionan automáticamente un identificador único para los registros de las tablas, se optó por permitir la edición y eliminación de datos únicamente para las tablas que tengan una clave primaria. Las tablas que no la tienen solo pueden recibir nuevos registros.

Para acceder a la interfaz de edición de registros, haga clic derecho en el nodo de la tabla y seleccione la acción Data Actions > Edit Data:

La interfaz tiene un editor SQL donde puede filtrar y ordenar registros. Para evitar que la interfaz solicite demasiados registros, hay un campo que limita la cantidad de registros a mostrar. La cuadrícula de registros tiene nombres de columna y tipos de datos. Las columnas que pertenecen a la clave primaria tienen un icono de llave junto a su nombre.
