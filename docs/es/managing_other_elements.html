Administración de otros elementos

Todas las estructuras de PostgreSQL pueden administrarse mediante el uso de plantillas SQL. Esto da al usuario más control que usar formularios gráficos para manipular las estructuras.

Por ejemplo, consideremos las secuencias dentro del esquema public de la base de datos ds2. Para crear una nueva secuencia, haga clic derecho en el nodo Sequences y elija Create Sequence.

Tras cambiar el nombre de la secuencia, puede descomentar otras opciones del comando y configurarlas según sus necesidades. Cuando todo el comando se vea bien, simplemente ejecútelo y se creará la nueva secuencia:

Con clic derecho en una secuencia existente, puede modificarla o eliminarla. Funcionará de la misma forma que la creación, usando una plantilla SQL que el usuario modifica.
