Funciones adicionales

Configuración de usuario

También en la esquina superior derecha, al hacer clic en el icono con forma de engranaje, OmniDB abrirá la ventana emergente User Settings (Configuración de usuario). Está compuesta por cuatro pestañas:

  • Shortcuts (Atajos): permite al usuario cambiar sus atajos de teclado en OmniDB.
  • Options (Opciones): permite al usuario cambiar el tamaño de fuente de la interfaz y configurar las opciones relacionadas con CSV (codificación, delimitador). El tema de OmniDB (claro/oscuro) se determina automáticamente según la preferencia de esquema de color del sistema operativo.
  • Formatting (Formato): configura cómo el formateador de SQL (la acción Indent SQL) reescribe su consulta: carácter de sangría (espacios o tabulador), tamaño de sangría (2/3/4), estilo de comas (al principio/al final) y capitalización de palabras clave (conservar/MAYÚSCULAS/minúsculas).
  • Password (Contraseña): permite al usuario cambiar su contraseña.

Ayuda contextual

La mayoría de los nodos del árbol (generalmente los de agrupación, como Schemas o Tables) ofrecen ayuda contextual. Se accede a esta función haciendo clic derecho sobre el nodo del árbol. Al hacer clic en la opción Doc: ..., OmniDB abre la página específica de la documentación de PostgreSQL en línea en su navegador web (el navegador predeterminado del sistema en la aplicación de escritorio, o una nueva pestaña cuando se ejecuta como OmniDB Server basado en navegador). También elige la versión de documentación adecuada para el servidor PostgreSQL al que está conectado.

Snippets

La Workspace Window (ventana de espacio de trabajo) tiene una pestaña externa fija con una función muy útil llamada Snippets (fragmentos de código). Con esta función puede almacenar consultas, instrucciones de comandos y cualquier otro tipo de texto que desee. También puede organizar los fragmentos en un árbol de directorios según sus preferencias. Todos los directorios y fragmentos que cree se almacenan dentro de la base de datos de usuario omnidb.db y persisten cuando actualiza OmniDB.

Gestión de backends

Al hacer clic derecho en el nodo raíz del árbol, mover el puntero del ratón hacia Monitoring (Monitorización) y luego hacer clic en Backends, el usuario puede ver toda la actividad que ocurre en la base de datos. Cierta información está oculta para los usuarios normales; solo los superusuarios de la base de datos pueden verla.

Al hacer clic en la X de la columna Actions (Acciones), puede finalizar el backend. Aparecerá una ventana emergente de confirmación.

Propiedades y DDL

Al hacer clic en la mayoría de los objetos de la vista de árbol (tablas, secuencias, vistas, roles, bases de datos, etc.), el usuario podrá ver una lista muy completa de propiedades del objeto.

En el otro panel, llamado DDL, el usuario podrá ver el código fuente DDL en SQL que se puede usar para recrear el objeto. El usuario puede copiar este texto y pegarlo donde desee.

Exportar datos

La Query Tab (pestaña de consulta) ofrece una forma de guardar los datos de los resultados de una consulta en un archivo CSV o XLSX. Al hacer clic en el botón Export Data (Exportar datos), se inicia un backend cancelable que guarda los datos en el archivo. Una vez finalizado, OmniDB proporciona un enlace llamado Save (Guardar), para que el usuario pueda descargar el archivo.

Todos los archivos se almacenan en una carpeta temporal dentro de la carpeta de OmniDB. OmniDB limpia esta carpeta regularmente, conservando solo los archivos de menos de 24 horas de antigüedad.

Historial de consultas

Desde la Query Tab puede hacer clic en el botón Command History (Historial de comandos) para ver un historial de consultas completo, navegable y con función de búsqueda.

Consola SSH

OmniDB también ofrece una consola SSH completa.
