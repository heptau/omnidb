Herramienta de configuración de OmniDB

Nota: la utilidad de línea de comandos independiente omnidb-config/omnidb-config-app/ omnidb-config-server descrita en esta página pertenecía a la compilación anterior basada en Python/Django y no forma parte de la versión actual. El único binario omnidb-server solo acepta -A/--app (modo aplicación de escritorio) y -d/--homedir (elegir el directorio home), documentados en el capítulo Instalación. Las tareas de mantenimiento que ofrecía la antigua herramienta todavía pueden realizarse manualmente, como se describe a continuación.

Directorio home

OmniDB almacena todo — la base de datos omnidb.db (usuarios, conexiones y otros datos de la aplicación) y una carpeta temp para los archivos exportados — en un único directorio home. Por defecto es ~/.omnidb/omnidb-app (modo escritorio) o ~/.omnidb/omnidb-server (modo servidor); pase -d /alguna/ruta para usar uno diferente.

Crear un usuario

Actualmente no hay ninguna opción de CLI para crear un usuario sin abrir OmniDB. En la primera ejecución sobre un directorio home vacío, OmniDB crea automáticamente un superusuario admin/admin predeterminado — inicie sesión con él y cree más usuarios desde la pantalla Users, o cambie la contraseña predeterminada.

Vacuum

OmniDB tiene una única base de datos SQLite, omnidb.db, que almacena todos los usuarios, conexiones y demás datos relacionados con OmniDB. Al ser un simple archivo SQLite, puede compactarla (vacuum) con cualquier cliente SQLite mientras OmniDB no esté en ejecución, por ejemplo:

user@machine:~$ sqlite3 ~/.omnidb/omnidb-app/omnidb.db 'VACUUM;'

Restablecer la base de datos

Si desea eliminar toda la información de OmniDB y obtener una base de datos limpia, como recién instalada, cierre OmniDB y elimine (o mueva a otro lugar) el archivo omnidb.db del directorio home. Se crea automáticamente uno nuevo y vacío — con un nuevo usuario predeterminado admin/admin — la próxima vez que se inicie OmniDB. Use esto con precaución: no se puede deshacer.

Eliminar archivos temporales

Los resultados de consultas exportados (CSV/XLSX/etc.) se escriben en la carpeta temp dentro del directorio home. Es seguro eliminar su contenido manualmente en cualquier momento mientras OmniDB no esté en ejecución; OmniDB la vuelve a crear según sea necesario.
