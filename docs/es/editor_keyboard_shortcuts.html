Atajos de teclado del editor

El editor SQL, el editor de la consola y el visor de DDL/Propiedades de OmniDB están todos construidos sobre el editor de código Ace, que incluye su propio conjunto amplio de atajos de teclado para editar, seleccionar y navegar por el texto. Este capítulo los enumera como referencia. Son independientes de los propios atajos de OmniDB a nivel de aplicación (Ejecutar consulta, Cancelar consulta, cambiar de pestaña, etc.), que residen en la pestaña Shortcuts del diálogo de configuración y pueden reasignarse desde allí — consulte Funciones adicionales para saber cómo abrirlo.
