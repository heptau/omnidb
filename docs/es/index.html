Resurgimiento del proyecto OmniDB

La herramienta de gestión de bases de datos ligera, potente y de código abierto ha vuelto para impulsar los flujos de trabajo de desarrollo modernos.

Resucitada activamente por los creadores de PgArachne — combinando una administración de bases de datos robusta con arquitecturas modernas de cliente ligero.

Instalar OmniDB

🍺

Homebrew macOS

Recomendado para macOS — el cask detecta automáticamente Apple Silicon o Intel.

brew install --cask heptau/tap/omnidb

¿Por qué OmniDB?

⚡

Reescrito para mayor velocidad

Python → Go. Las consultas se ejecutan y la interfaz responde sin un intérprete de por medio.

📦

Binario ultraligero

El antiguo shell de Electron/NW.js ha desaparecido. Ahora Wails impulsa la aplicación a través del webview nativo del sistema operativo.

🖥️

Todas las plataformas, una sola versión

macOS (Apple Silicon e Intel), Linux y Windows se compilan y publican a partir de la misma versión.

🗄️

Cinco motores, un solo espacio de trabajo

PostgreSQL, MySQL, MariaDB, Oracle y SQLite en un único espacio de trabajo con pestañas.

🔒

Reforzado activamente

Se publican correcciones reales de forma continua — inyección SQL, XSS, IDOR. Consulte el registro de cambios.

📤

Exporte a cualquier formato

Directamente a CSV, XLSX, TSV, Markdown, JSON o XML.
