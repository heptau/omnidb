Instalace

OmniDB nabízí 2 druhy balíčků, aby vyhověla potřebám každého uživatele:

  • Aplikace OmniDB: Na pozadí spouští webový server na náhodném portu a poskytuje zjednodušené okno webového prohlížeče pro použití rozhraní OmniDB bez jakéhokoli dalšího nastavování. Působí prostě jako desktopová aplikace.
  • Server OmniDB: Spouští webový server na náhodném portu, nebo na portu zadaném uživatelem. Uživatel se k němu musí připojit přes webový prohlížeč. Poskytuje správu uživatelů a je ideální pro provoz na serveru v síti uživatelů.

Aplikaci i server lze nainstalovat na stejný počítač.

Aplikace OmniDB

Důležité: Původní repozitář https://github.com/OmniDB/OmniDB/releases obsahuje pouze staré verze (přibližně do roku 2020) a už se dále neudržuje — co se od té doby změnilo, najdete v části Starší funkce a historie.

Pro aktuální verze použijte stránku s vydáními oživeného projektu. Od přepsání do Go je každé vydání jediným samostatným archivem pro danou platformu — bez instalátoru, bez nutnosti nejprve instalovat samostatný runtime:

  • macOS (Apple Silicon nebo Intel): OmniDB-<version>-macOS-osx-arm64.zip / OmniDB-<version>-macOS-osx-x64.zip
  • Linux x64: OmniDB-<version>-linux-x64.tar.gz
  • Windows x64: OmniDB-<version>-win-x64.zip

Rozbalte archiv pro vaši platformu a spusťte aplikaci/binárku OmniDB uvnitř — to je celá instalace. Sestavení pro Linux a Windows vznikají v CI při každém vydání, ale zatím nebyla ověřena na reálném hardwaru, na rozdíl od sestavení pro macOS; pokud narazíte na problém specifický pro jednu z těchto platforem, založte prosím issue.

Instalace přes Homebrew (pouze macOS – doporučeno)

Pro uživatele macOS, kteří dávají přednost správci balíčků, je OmniDB k dispozici přes vlastní Homebrew tap:

# Instalace nejnovější verze:
brew install --cask heptau/tap/omnidb
# Pozdější aktualizace:
brew upgrade heptau/tap/omnidb

Homebrew automaticky stáhne správný ZIP pro vaši architekturu (Apple Silicon nebo Intel), rozbalí ho a umístí OmniDB.app do vaší složky Aplikace.

Definice casku je udržována zde: heptau/homebrew-tap – omnidb.rb

Přímé stažení (všechny platformy)

Otevřete nejnovější vydání a v jeho sekci Assets stáhněte archiv odpovídající vašemu OS/architektuře z výše uvedeného seznamu. Názvy souborů u vydání obsahují číslo verze, takže neexistuje pevná URL adresa „vždy nejnovější“, na kterou by šlo odkázat přímo — vždy použijte samotnou stránku s vydáními.

Rozbalte archiv pro vaši platformu a spusťte aplikaci obvyklým způsobem: na macOS přetáhněte OmniDB.app do složky Aplikace a otevřete ji z Launchpadu/Spotlightu nebo příkazem open -a OmniDB; na Linuxu spusťte binárku OmniDB přímo; na Windows spusťte OmniDB.exe.

Server OmniDB

Stejný archiv s vydáním obsahuje také omnidb-server — samostatnou binárku bez grafického rozhraní vedle desktopové aplikace (desktopová aplikace ve skutečnosti tuto stejnou binárku interně spouští jako podřízený proces a vynucuje režim aplikace). Spusťte ji přímo pro serverový režim dostupný z prohlížeče, bez jakéhokoli desktopového obalu:

user@machine:~$ ./omnidb-server
omnidb-server: listening on 127.0.0.1:52149 — open http://127.0.0.1:52149/omnidb_login/ in your browser

OmniDB standardně naslouchá pouze na 127.0.0.1 a automaticky si vybere volný port. Obojí můžete zadat explicitně:

user@machine:~$ ./omnidb-server -p 8080 -H 0.0.0.0
omnidb-server: listening on 0.0.0.0:8080 — open http://0.0.0.0:8080/omnidb_login/ in your browser

Kompletní přehled možností a doporučená nasazení najdete v části Nasazení omnidb-server (mimo jiné proč se nedoporučuje vystavovat -H 0.0.0.0 přímo internetu bez reverzní proxy před ním — chybí zabudovaná podpora TLS).

OmniDB s Oracle

Ani aplikace, ani server OmniDB nevyžadují k připojení k Oracle žádný další software — na rozdíl od předchozích vydání není potřeba samostatná instalace Oracle Instant Client. Konektivita k Oracle je implementována nativně (čistě v Go), takže funguje po vybalení stejným způsobem jako u každé jiné podporované databáze.

Uživatelská databáze OmniDB

Při prvním spuštění server i aplikace vytvoří soubor ~/.omnidb/omnidb-app/omnidb.db (pro aplikaci OmniDB) nebo ~/.omnidb/omnidb-server/omnidb.db (pro server OmniDB) v domovském adresáři uživatele, pokud ještě neexistuje — spolu s výchozím superuživatelským účtem admin/admin, se kterým se lze ihned přihlásit. Tento soubor se také nazývá uživatelská databáze a obsahuje všechny uživatele, připojení a další data aplikace. Pokud už existuje (např. po aktualizaci), OmniDB ho použije tak, jak je — nikdy ho automaticky nepřepíše ani neresetuje.
