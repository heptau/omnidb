Další funkce

Uživatelská nastavení

Také v pravém horním rohu, kliknutím na ikonu ozubeného kola, OmniDB otevře vyskakovací okno User Settings (Uživatelská nastavení). Skládá se ze čtyř karet:

  • Shortcuts (Zkratky): Umožňuje uživateli měnit klávesové zkratky v OmniDB.
  • Options (Možnosti): Umožňuje uživateli měnit velikost písma rozhraní a konfigurovat volby týkající se CSV (kódování, oddělovač). Motiv OmniDB (světlý/tmavý) se automaticky určuje podle preference barevného schématu vašeho operačního systému.
  • Formatting (Formátování): Nastavuje, jak SQL formátovač (akce Indent SQL, Formátovat SQL) přepisuje váš dotaz — znak odsazení (mezery nebo tabulátor), velikost odsazení (2/3/4), styl čárek (na začátku/na konci řádku) a velikost písmen klíčových slov (zachovat/VELKÁ PÍSMENA/malá písmena).
  • Password (Heslo): Umožňuje uživateli změnit si heslo.

Kontextová nápověda

Většina uzlů stromu (obvykle seskupujících, jako jsou Schemas nebo Tables) nabízí kontextovou nápovědu. K této funkci se dostanete kliknutím pravým tlačítkem na uzel stromu. Když kliknete na volbu Doc: ..., OmniDB otevře konkrétní stránku online dokumentace PostgreSQL ve vašem webovém prohlížeči (v desktopové aplikaci v systémovém výchozím prohlížeči, při běhu jako prohlížečový OmniDB Server jako nová karta). Zároveň zohlední verzi PostgreSQL, ke které jste připojeni, a přesměruje na odpovídající stránku.

Úryvky (Snippets)

Workspace Window (okno pracovního prostoru) má pevnou vnější kartu s užitečnou funkcí nazvanou Snippets (Úryvky). Pomocí této funkce můžete ukládat dotazy, příkazové instrukce a jakýkoli jiný text, který potřebujete. Úryvky si také můžete uspořádat do adresářového stromu podle svých představ. Všechny adresáře a úryvky, které vytvoříte, se ukládají do uživatelské databáze omnidb.db a zůstanou zachovány i po aktualizaci OmniDB.

Správa backendů

Kliknutím pravým tlačítkem na kořenový uzel stromu, přesunutím kurzoru na Monitoring a kliknutím na Backends může uživatel vidět veškerou aktivitu probíhající v databázi. Některé informace jsou pro běžné uživatele skryté, vidět je mohou pouze superuživatelé databáze.

Kliknutím na X ve sloupci Actions (Akce) můžete backend ukončit. Zobrazí se potvrzovací vyskakovací okno.

Vlastnosti a DDL

Kliknutím na většinu objektů ve stromovém zobrazení (tabulky, sekvence, pohledy, role, databáze atd.) si uživatel může zobrazit velmi podrobný seznam vlastností daného objektu.

Na dalším panelu s názvem DDL si uživatel může prohlédnout zdrojový SQL kód DDL, který lze použít k opětovnému vytvoření objektu. Uživatel může tento text zkopírovat a vložit, kam potřebuje.

Export dat

Karta Query Tab (Dotaz) nabízí možnost uložit data z výsledků dotazu do souboru CSV nebo XLSX. Jakmile kliknete na tlačítko Export Data, spustí se zrušitelný backend, který začne ukládat data do souboru. Jakmile je hotovo, OmniDB nabídne odkaz Save (Uložit), pomocí kterého si uživatel může soubor stáhnout.

Všechny soubory se ukládají do dočasné složky uvnitř složky OmniDB. OmniDB tuto složku pravidelně čistí a ponechává pouze soubory novější než 24 hodin.

Historie dotazů

Na kartě Query Tab (Dotaz) můžete kliknout na tlačítko Command History (Historie příkazů) a zobrazit si úplnou, procházitelnou a prohledávatelnou historii dotazů.

SSH konzole

OmniDB dále nabízí plnohodnotnou SSH konzoli.
