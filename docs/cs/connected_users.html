Připojení uživatelé

Sekce Připojení uživatelé ukazuje, kdo je právě připojen k databázovému serveru — backendy PostgreSQL, vlákna MySQL/MariaDB, relace Oracle a SQL Serveru, připojení (attachments) Firebirdu —, co kdo z nich dělá, a umožňuje kterékoli z nich ukončit. Nahrazuje starší položky kontextové nabídky stromu databáze specifické pro jednotlivé stroje: Připojení serveru (Backends), Seznam procesů a Relace.

Podporováno: PostgreSQL, MySQL, MariaDB, Oracle, SQL Server a Firebird. SQLite nic takového nezná a zobrazí Zobrazení připojených uživatelů není pro připojení … podporováno.

Otevření sekce

Klikněte na ikonu Připojení uživatelé na levé liště. Stejně jako Monitorování, Oznámení a Oprávnění pracuje s připojením, které je už otevřené v sekci Databáze: nahoře se zobrazuje pruh záložek otevřených připojení a seznam patří vybrané záložce. Není-li otevřeno žádné připojení, zobrazí se Není otevřeno žádné připojení.

Seznam se načte při vstupu do sekce a při každém přepnutí na jinou záložku připojení; sám se neobnovuje. Chcete-li ho načíst znovu, klikněte pravým tlačítkem do mřížky a zvolte Obnovit. Počet řádků se zobrazuje nad mřížkou (Počet záznamů: …).

Sloupce

Sloupce jsou kompaktně seskupené (například ID pod názvem nebo adresa a port na jednom řádku); po najetí myší na záhlaví sloupce se zobrazí vysvětlení, co sloupec ukazuje a ze kterého sloupce katalogu pochází.

  • PostgreSQL (pg_stat_activity): PID, Databáze, Uživatel, Klient, Aplikace, Start procesu / Start transakce, Start dotazu / Změna stavu, Čekání, Stav, ID transakce, ID dotazu, Typ procesu.
  • MySQL/MariaDB (seznam procesů): Uživatel (s ID připojení), Host, Databáze, Příkaz, Čas (s), Stav.
  • Oracle (v$session): SID (se Serial#), Uživatel, Stav, Schéma, Klient, Program, Modul / akce, Info o klientovi, Přihlášení, Nečinnost (s), SQL ID, Čekání, Blokující SID.
  • SQL Server (uživatelské relace): ID relace, Přihlašovací jméno, Hostitel, Program, Stav.
  • Firebird (mon$attachments, bez vlastního připojení OmniDB): ID připojení, Uživatel, Vzdálená adresa, Stav.

U PostgreSQL a Oracle jsou procesy na pozadí a systémové procesy ve výchozím stavu skryté; chcete-li je zahrnout, zaškrtněte nad mřížkou Zobrazit systémové procesy (políčko se zobrazí jen tehdy, když takové řádky existují).

Zobrazení dotazu relace

U PostgreSQL, MySQL a MariaDB otevře kliknutí na řádek pod mřížkou panel Text dotazu s příkazem, který daná relace právě provádí (nebo provedla naposledy), se zvýrazněnou syntaxí a jen pro čtení. Odtud ho můžete zkopírovat, nebo pomocí Otevřít v novém dotazu pokračovat v práci s ním v běžné kartě dotazu, například na něm spustit Explain.

Ukončení relace

Klikněte pravým tlačítkem na řádek a zvolte Ukončit. Po potvrzení OmniDB ukončí relaci způsobem, který je pro daný stroj obvyklý — pg_terminate_backend() v PostgreSQL, KILL v MySQL/MariaDB a SQL Serveru, ALTER SYSTEM KILL SESSION … IMMEDIATE v Oracle, smazáním řádku z mon$attachments ve Firebirdu — a znovu načte seznam. K tomu je potřeba odpovídající oprávnění na databázovém serveru. Stejná kontextová nabídka nabízí také Kopírovat a Zobrazit obsah pro buňku, na kterou jste klikli.
